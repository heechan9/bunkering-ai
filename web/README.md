# 병커시유 Ocean Lab 웹 소스

시연: https://bunkering-ocean-lab.hc24734503.chatgpt.site/

## 포함 범위

Sites 배포 7판의 소스 커밋 `9cd5be767d7829ac5779c1db0b341c96a7397741`에서 추적된 121개 파일을 `ocean-lab/`에 바이트 그대로 보존했습니다. 원본 소스의 작성 이력은 Sites 저장소에 있으며, GitHub에서는 이번 수입 시점부터 변경을 추적합니다. 원본 전체 Git 이력을 옮겼다는 뜻은 아닙니다. `SOURCE_IMPORT.json`의 파일별 SHA-256으로 동일성을 확인할 수 있습니다.

- Three.js 선박 모형, 안내형 항로 선택→운항 체험→정책 비교 흐름, 항차 기록 재생 및 정책 비교
- 호르무즈·수에즈·희망봉·바브엘만데브·대만해협·도버·울산의 지형 표시 및 지구본
- 원본 1,600 에피소드의 규칙 정책 반복을 제거한 700개 정책/체크포인트/사례 조합, 19,030개 전이. 공유 시장 사례는 100개이며 독립 사례 700개가 아닙니다.
- 지형 및 선박 모형은 설명용입니다. 실제 항차 자료·항만 공급제약·선박 물리모델을 추가한 것이 아닙니다.

## 로컬 실행

Node.js 22.13 이상 및 package.json에 지정된 pnpm 11.25.0을 사용합니다. Windows에서는 Anaconda/Python 환경과 별개인 Node 프로젝트이며, 쉘 스크립트가 필요한 보조 명령은 WSL 또는 Git Bash를 사용합니다.

```sh
cd web/ocean-lab
pnpm install --frozen-lockfile
pnpm dev
```

실행 시 출력된 로컬 주소를 엽니다. 일반 로컬 실행 경로의 기본 개발 포트는 5173입니다. 빌드는 `pnpm build`입니다. `.sites-runtime`은 환경별 임시 실행 설정으로 포함하지 않습니다.

## 배포와 검증 경계

GitHub에 소스를 반영하는 작업과 Sites 배포는 별개입니다. 현재 GitHub push로 웹이 자동 배포되도록 연결하지 않았습니다. 기존 Sites 주소와 접근 권한은 유지합니다. `.openai/hosting.json`은 기존 프로젝트 식별 정보이며 인증 토큰이 아닙니다. `.env`, node_modules, 빌드 결과 및 인증 정보는 수입 대상에 없습니다.

`public/data/integration-review.json`은 이전 웹 데이터 대조 기록입니다. 이번 소스 수입을 새 모델 평가나 새 브라우저·모바일/GPU 검증으로 해석하지 않습니다. 원본 웹 README의 과거 검증 설명도 해당 시점의 이력입니다. 진단 기준 문서는 연구 커밋 `bc3293f06e4118e5d245a716b2402fe7080905b8`을 참조합니다.
