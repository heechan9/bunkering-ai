# NTNU 별도 환경 재학습 — 효율 미확정 조건부 연구

## 원자료 확인

Mendeley `10.17632/c95ph5mfjb.1`, CC BY 4.0. Sara Faugstad Amundsen, Sondre Vangberg, Mohamed Kais Msakni, *Green fuels in liner feeder shipping: integrated network design, speed optimization, and bunker management*.

공개 ZIP의 `vessel_fuel_specifications.json`에서 `energy_consumption`은 연료 독립적인 추진에너지 MWh/h, `tank_capacity_kwh`는 연료에너지 저장용량, `energy_density_kwh_per_kg`는 저위발열량이다. 700 TEU의 5.9353 MWh/h × 3.6 = 21.36708 GJ/h. 추진에너지에서 연료에너지로 변환하는 효율은 공개 JSON에 없다. 연결된 원문에서 효율 정의를 확인하지 못했으므로 원 논문 재현으로 표시하지 않는다.

η=1.0은 기존 에너지 대용치 해석, η=0.5 및 0.4는 **검증되지 않은 민감도 가정**이다. 연료에너지 수요 = 추진에너지율 × 구간시간 / η. 실제 연료량·실제 절감률로 해석하지 않는다.

## 고정한 실험 설계

- 생산 체크포인트를 불러오거나 수정하지 않는 새 CPU DQN. 12입력, 64×64 은닉층, 5행동. 시드42/43/44 각각6,000에피소드, 4구간. Double DQN, γ=1, Adam 0.001, batch128, replay30,000, 100에피소드마다 타깃 갱신. ε는1에서0.05로 감소.
- 항로: 허브→비허브3곳→허브. 기존 시드0–19 항로 및 역방향 제외. 역방향을 같은 항로로 취급하여 분할 중복 방지. Baltic/MED1/MED2/Norwegian coast 각각100학습·20검증·30평가 항로. WAF50항로는 지역 외부 평가만 사용.
- 선형계획으로 탱크 용량상 불가능한 경우를 식별하고 학습·비교에서 제외. 제외 건수는 audit.json에 공개. 시간 초과는 제외하지 않고 성능에 반영.
- 6선형, 효율3가정, 속력14kn 고정, 초기잔량50%, 최소잔량10%. 모든 급유항에서 MGO공급 가능 여부 확인. 가상 인프라 제외.
- 상태: 잔량, 진행단계, 시간여유, 항해시간 비율, 남은 구간별 수요4개와 가격4개. 가격÷0.1 USD/kWh, 탱크 기준 수요; 데이터 기반 정규화나 clipping 없음. 모든 정책에 동일한 공개 시나리오의 정적 가격 제공. 실현 미래가격 예측이 아니다.
- 행동은 다음 구간+예비량 최소급유와 남은 전체 수요(탱크 한도) 사이의5단계. 안전은 이 구조적 가드의 효과이며 학습 성과로 주장하지 않는다.
- 연료 구입비 음수 보상, 마지막 잔량은 항로 최저가격으로 회수. 시간 초과 비례 패널티. 1,000에피소드마다 검증목적값을 평가해 체크포인트 선택; 시험 결과로 선택하지 않는다.
- 비교: 다음 구간 최소급유, 다음 저가항까지 확보 규칙, 고정항로 재고 LP. 초기·최종잔량을 동일 최저가격으로 평가한 조정비용. LP는 급유정지 시간 제약 없는 비용 하한이며 시간은 사후 평가.
- 시간은 항해+급유만 포함. 대기·하역·화물수송·실제 운항 변동·가격 예측 제외. 동일 고정속력·항로 내 정책별 소비에너지는 같아 비용 차이는 연료 절감이 아니다.

## 실행

```bash
python research/ntnu_bunkering/retrain.py
python research/ntnu_bunkering/check_retraining.py
```

Python, NumPy, pandas, SciPy, PyTorch 및 기존 experiment.py의 import 의존성 필요. 원자료는 `inputs/supplementary_materials.zip`에 두며 SHA-256 검증한다. 결과는 `results/retraining/`, 후보 가중치는 `candidate_42.pt` 등으로 분리한다. 운영 모델 교체와 배포는 하지 않는다.

## 결과 및 판정

학습7,200조건·검증1,440조건, 내부 평가2,160조건, 외부900조건 중 탱크 용량상 불가능한8조건 제외하여892조건 평가. 총3,052조건×6정책=18,312평가 행. 서로 다른 선형·효율 조건은 같은 항로를 공유하므로 통계적으로 독립인3,052항해라고 해석하지 않는다.

| 평가 | 효율 가정 | DQN의 최소급유 대비 비용 감소 (3시드 범위) | DQN의 저가항 규칙/LP 대비 비용 증가 |
|---|---:|---:|---:|
| 내부 미학습 항로 | 40% | 0.307–0.366% | 0.069–0.128% |
| 내부 미학습 항로 | 50% | 0.168–0.197% | 0.030–0.059% |
| 내부 미학습 항로 | 100% 대용치 | 0.0019–0.0027% | 0.0007–0.0014% |
| 미학습 서아프리카 | 40% | 1.576–1.740% | 0.274–0.441% |
| 미학습 서아프리카 | 50% | 1.416–1.539% | 0.093–0.219% |
| 미학습 서아프리카 | 100% 대용치 | 0.195–0.238% | 0–0.043% |

비용은 각 효율·평가군에서 모든 정책이 안전·기한을 충족한 동일 조건 집합의 총비용 비교다. 안전율은 평가한 용량 가능 조건에서 모두100%이며 구조적 가드에 의한 결과다. 기한 포함 성공률은 내부96.67–97.36%, 외부82.00–83.90%로 정책 간 동일하다. 외부 효율40%는 불가능8조건을 제외한 분모이므로 효율 간 성공률을 직접 우열 비교하면 안 된다.

이번 정적 가격·고정항로 조건에서는 저가항 규칙이 LP 비용과 같았다. DQN은 그 규칙보다 비용이 높거나 같았으며, **운영 모델 교체하지 않음**으로 판정한다. 원자료의 효율 정의가 확보되어도 이번 결과만으로 교체할 이유는 없다. 정확한 에너지 해석으로 재검증할 연구용 후보로만 보관한다.

검증: 수계산 LP 사례, 불가능 구간, 가드의 재고 보존·잔량, 항로 중복, 정책별 대응 행, 유한 비용, 모든 평가 행의 LP 하한 확인을 통과했다. 체크포인트 선택은 검증 집합만 사용했다. 신뢰구간이나 실제 선박 실증은 수행하지 않았다.

원자료 설명의 21.4≈21.2 GJ/h는 저자가 반올림이라고 기술했으나 독립적으로 해소하지 못한 불일치다. 실제 계산에는 JSON의5.9353 MWh/h를 사용했다. 출처 ZIP·모델·코드 해시와 실행 라이브러리 버전은 audit.json에 기록했다.
