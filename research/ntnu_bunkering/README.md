# NTNU MGO 급유정책 이식 진단 — 2026-10-05

## 판정

외부 연구용 벤치마크로 채택할 가치가 있다. 현재 DQN을 NTNU 조건에 바로 운영 적용하거나 재학습 모델로 교체할 근거는 없다. 이 실험은 데이터 어댑터를 통한 동결 가중치 이식 진단이며 원래 환경에서의 공식 성능 평가를 대체하지 않는다.

출처: Sara Faugstad Amundsen, Sondre Vangberg, Mohamed Kais Msakni, NTNU, “Data for: Green fuels in liner feeder shipping: integrated network design, speed optimization, and bunker management”, v1, 2026-09-29, DOI https://doi.org/10.17632/c95ph5mfjb.1 , CC BY 4.0. 본 코드는 원자료를 변경하지 않고 구성 항로와 분석 가정을 추가했다. 원본 ZIP 28,507 bytes와 공개 SHA256 일치 확인. 설명의6개 네트워크와 달리 배포파일에는5개 항만 네트워크가 있어5개만 사용했다.

## 실험

5개 네트워크 × 20개 고정 시드 항로 × 6개 선박 크기 × 3개 속도(10/14/18kn) = 1,800조건. 허브→무작위3항만→허브 항로를 구성했다. 관측 항차가 아니다. 7전략 총12,600회 평가, 모델 재학습 없음.

- 프로젝트의 FixedFuelingStrategy, PriceReactiveStrategy, SafeStockStrategy 코드를 직접 호출.
- 공식 release dqn_final.pt를 동결 추론. SHA256은 audit.json에 기록.
- 다음 구간 소비+10%잔량 확보 규칙, 해당 규칙을 DQN에 덧붙인 guarded_dqn, 고정항로·속도 재고 LP와 비교.
- 초기재고50%, NTNU 잔량10%; 기존 safe_stock 발동15%, 기존 급유요청90%/상한95% 유지.
- 비용은 USD. 종료 재고 차이는 해당 항로 최저가격으로 평가하여 초기−종료 재고가치를 구매비용에 더한다. 실패 정책의 싼 비용을 절감으로 세지 않고 동일한 안전·시간 충족 사례끼리 비교한다.

|전략|잔량 조건 충족|잔량+시간 조건 충족|
|---|---:|---:|
|출항 시 급유|98.61%|89.11%|
|가격반응 규칙|86.61%|77.94%|
|기존 안전재고 규칙|89.78%|80.83%|
|동결 DQN|99.94%|90.22%|
|DQN+다음 구간 잔량 보정|100%|90.22%|
|다음 구간 필요량 규칙|100%|90.33%|
|재고 LP|100%|90.33%|

동결 DQN과 다음 구간 필요량 규칙이 함께 안전·시간 조건을 만족한1,624조건에서 DQN의 재고가치 조정 총비용은2.85% 더 높았다. DQN과 LP의 같은1,624조건에서는3.25% 더 높았다. 서로 다른 공통 표본을 사용하는 전략별 LP 차이를 직접 순위로 비교하지 않는다. 가격반응 규칙의 공통성공 사례 LP 차이0%도 높은 실패율을 가리는 선택효과가 있다.

14kn 기준속도만 보면600조건 중 DQN/다음구간규칙/LP 모두 잔량100%, 시간포함98%였다. DQN의 유일한 잔량실패는 WAF 시드7,700TEU,18kn 감도조건이었다. 원래 환경의 DQN이 실패했다는 의미는 아니다.

## 확인된 보완점과 한계

1. DQN1,800조건 중1,674조건에서 가격/이동평균 입력이 기존 정규화 범위에서 잘렸다. 에너지당 가격을 자료의 발열량으로 USD/t로 변환했지만 가격 차이를 잃는 구간이 많다. 재학습 전 입력 스케일·학습분포 재설계가 필요하다.
2. DQN 입력에 다음 구간 거리·급유 공급 여부·급유시간이 없고, 양수 행동은 현 항만 급유로 통합했다. 원래 소비후급유에서 이식환경은 출항전급유로 순서가 바뀌었다. MA30은 일별이 아닌 방문항만 가격의 최대30개 평균이고 환율1300/SFC0.19는 상수다. 따라서 제한된 어댑터 시험이다.
3. 원본 energy_consumption은 추진에너지로 설명되어 있고 변환효율이 명시되지 않았다. 이 실험은 이를 저장에너지 수요 대리값으로 사용하므로 실제 연료소비량이 아니다.14kn 수치를 기준으로10/18kn은 출력 속도³ 가정. 실측 절감률 주장 금지.
4. 시간은 항해+급유만 포함한다. 하역·대기·화물수요·전체 네트워크 제약은 생략하여 낙관적이다. 재고 LP는 비용만 최적화하고 시간은 사후 검사한다. NTNU 논문 전체 재현이나 일정준수 보장은 아니다.
5. MGO와 기존/발표된 공급으로 표시된 항목만 사용했다. 미래 인프라 가정은 제외했다. NTNU 표기 자체를 현재 실재시설로 별도 검증한 것은 아니다.
6. 최소필요량 규칙과 보정 DQN은 다음 구간 수요를 정확히 아는 결정론적 조건이다. 수요 예측오차에서는 다시 검증해야 한다. 보정의 효과를 DQN 학습성과로 귀속하지 않는다.
7. USDA는 항만별이 아닌 유종별 평균 시계열이라 이번 공간가격 실험에 혼합하지 않았다.

## 재현

저장소 requirements와 scipy, pandas, requests, torch, gymnasium 필요.

```bash
python research/ntnu_bunkering/acquire.py
python research/ntnu_bunkering/experiment.py
```

결과: results/summary.csv, by_speed.csv, audit.json 및 재실행으로 생성되는 episodes.csv. 원본·가중치는 Git에서 제외한다. 에너지 수지·탱크 상한·LP 비용 하한 검사를 실행 중 수행한다. 별도로 두 항만 손계산 최적해 및 단일구간 용량초과 불가능 사례를 확인했다.
