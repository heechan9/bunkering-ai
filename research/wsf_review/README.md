# WSF 공개자료 검토 — 2026-10-05

## 판정

미국 Washington State Ferries의 선대 단위 소비·예산·금융헤지 자료다. 소비·비용 회계 검산과 집계 지표 설계에 사용 가능하다. 개별 선박의 급유 장소·구매량·ROB 최적화 학습자료로 직접 사용하지 않는다.

원본:
- https://wsdot.wa.gov/sites/default/files/2025-12/Ferries-Report-FY2025FuelHedging.pdf
- https://wsdot.wa.gov/sites/default/files/2025-01/FY2024-WSF-Performance-Measures-Report.pdf

PDF 다운로드 후 FY2025 본문 p8 표2와 p9 Attachment A, p10 Attachment B를 이미지로 확인해 월별12행을 전사했다. 원본 SHA256은 results/audit.json. `python research/wsf_review/audit.py`로 합계 검산.

FY2025 실제 소비15,225,993갤런, 예산18,232,062갤런, 금융스왑 명목량10,290,000갤런. 월별 합계 모두 일치한다. 예산 대비16.49% 적게 소비했으나 서비스 축소·선박 운휴·전동화 공사 등이 섞여 있어 실제 효율향상이나 우리 모델의 연료절감률로 사용할 수 없다. 갤런 값을 밀도 없이 톤으로 바꾸지 않는다.

## 원문 불일치

- 요약의 $86,533 수취를 전체 헤지 순이익으로 읽으면 안 된다. 부록B에서 이는 마지막 스왑 하나의 금액이고, 전체 합계는 WSF가 지불한 $1,952,962로 표시돼 있다. 원문 숫자 간 모순으로 기록하며 기관 확인 없이 어느 쪽을 공식 정정하지 않는다.
- 월별 표시 정산액 합계는 -$1,952,961로 표시총액과 $1 차이. 반올림 가능성이 있지만 원인 확정하지 않는다.
- FY2025 표에 FY2024 제목이 남아 있고, 부록A와 B의 계약 가격도 서로 다르다. 같은 가격필드로 합치지 않는다.
- FY2021 소비는 FY2025 헤지보고서15,391,626과 FY2024 성과보고서15,415,327로 달라 연도 연결 시 검토 필요.

## 프로젝트 연결 범위

현 단계는 검토·전사·합계검산까지다. 선박 식별자, 급유 거래 시각, 항만별 실구매 가격, ROB가 없어 DQN 학습에 미사용. 금융스왑 명목량은 실물 구매량이 아니다. 선대 집계를 한바다나 NTNU 선박의 기록과 직접 결합하지 않는다. 월별 예산/실소비/헤지정산을 구분하는 검증 사례로 보존한다.
