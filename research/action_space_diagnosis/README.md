# 급유 행동 공간 진단 — 2026-10-07

## 결론

기존 NTNU 별도 재학습은 이미 예비연료 가드와 종료재고 회수가 포함돼 있다. 이를 다시 추가하기 전, 5개 등간격 구매량 행동이 연속 최적 구매량을 표현할 수 있는지 검사했다.

**새 합성 120조건 중 42조건에서 5개 행동의 최선 조합도 LP보다 비쌌다.** 총비용 기준 차이는 0.116964%, 개별 최대 1.402202%였다. 이 조건에서는 학습을 완벽하게 해도 행동 공간에 따른 차이가 남는다.

이는 기존 NTNU 18,312행의 오류 원인을 확정한 결과가 아니다. 기존 후보 가중치·원항차를 재실행하지 않았다. 새 자료 수집 없이 공개 코드의 구조적 제한을 확인한 별도 실험이다.

## 실험

- 기준 소스: main `7f753d072eb8caf4963fb8746ccb42b4c4766879`.
- 실제 `retrain.py`의 `quantity`, `experiment.py`의 `solve` 함수 AST만 읽어 실행한다. 별도 복사 구현이나 PyTorch 설치 없이 원 함수의 계산을 사용한다. 원본 파일 SHA-256은 결과에 기록한다.
- seed 20261007. 수작업 1조건과 균등분포로 만든 119조건. 구간 4개, 초기잔량 0.5, 예비잔량 0.1, 용량 1. 가격·수요는 무차원 합성 입력이다.
- 무작위 구간 수요 [0.12, 0.42), 가격 [0.7, 1.4). 모든 항만 공급 가능. 고정 가격을 사전에 아는 조건이다.
- 기존 5행동: 항차당 5^4=625개 행동열 전수 계산.
- 비교 6행동: 기존 5개에 다음 저가항까지 필요한 양을 구매하는 규칙 행동 추가, 6^4=1,296개 전수 계산.
- 전체 230,520개 행동열과 120개 LP 비교. 학습 실행이 아니다.
- 기존 회계와 동일한 구매비 + 최저가격×(초기잔량−종료잔량) 사용. 시간·고정 급유비·공급 불확실성은 포함하지 않았다.

| 비교 | 결과 |
|---|---:|
| 5행동 최선도 LP보다 비싼 조건 | 42/120 |
| 5행동 총비용/LP 총비용 − 1 | 0.116964% |
| 5행동 개별 최대 차이 | 1.402202% |
| 6행동 최선과 LP의 최대 절대 차이 | 4.44e-16 |
| 저가항 규칙 단독과 LP | 120조건 모두 허용오차 내 일치 |

6번째 행동이 기존 선택지를 포함하므로 최선값이 악화하지 않는 것은 구조상 보장된다. LP에 도달한 결과는 규칙 행동의 효과이며 DQN 학습 성과가 아니다. 이 작은 합성 표본을 다른 조건으로 일반화하지 않는다.

## 구체적 반례

`results/worst_case.json`에 구간별 구매·잔량·가격을 기록했다. 107번 조건에서 두 번째 항만의 연속 최적 구매량은 0.258486인데, 5행동 최선은 0.310481을 구매한다. 그 차이만큼 더 싼 마지막 항만 구매가 줄어든다. 최종잔량은 0.1로 같으므로 이 반례의 추가비용은 남은 재고량 차이가 아닌 구매 위치·물량 배분에서 발생한다.

이보다 단순한 수계산 반례도 테스트했다: 수요 [0.24,0.29,0.13,0.24], 가격 [1.13,0.90,1.27,0.72]에서 두 번째 항만 0.26, 마지막 항만 0.24 구매가 최적이다. 기존 5행동 최선은 이 비용에 도달하지 못한다.

## 채택 판단과 다음 실험

- 채택: 새 재학습 전에 연속 LP / 행동공간 최선 / 학습 정책을 따로 비교하는 진단 방식.
- 연구 후보: 다음 저가항 구매량을 포함한 행동 공간. 기존 5출력 체크포인트에는 그대로 끼워 넣을 수 없다. 새 6출력 학습 모델이 필요하다.
- 보류: 공식 모델 교체, DQN 성능 향상 및 실제 절감 주장.
- 기존 가중치 재실행 시 전체 비용 차이를 `(5행동 최선−LP) + (DQN−5행동 최선)`으로 분해한다. 이는 같은 항차·같은 안전/시간·회계 조건에서만 유효하다. 여기서는 시간 제약을 제외했으므로 과거 시간포함 수치와 직접 합치지 않는다.
- 정적 가격·공급가능 조건에서는 이미 규칙이 LP에 도달하므로 DQN이 이를 이기는 것을 목표로 삼지 않는다. 불확실 조건을 추가할 때에는 규칙도 같은 관측 정보만 사용하도록 해야 한다.
