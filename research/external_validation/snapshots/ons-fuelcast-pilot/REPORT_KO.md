# ONS · FuelCast 기존 DQN 연결 실험

결론: FuelCast는 실측 소비 변동을 주는 외부 스트레스 검증 자료로 채택할 가치가 있다. ONS는 항로 상황 설명·시나리오 근거로 유지한다. 이번 결과는 재학습이나 실선 비용 개선의 증거가 아니다.

## 실행 조건
공식 체크포인트 해시를 확인한 기존 Double DQN과 기존 FixedFueling, PriceReactive, SafeStock을 그대로 평가했다. FuelCast의 이전 시간순 테스트 구간에서 연속 24시간 블록 120개(Poseidon 73, Triton 17, Ceto 30)를 선택하고 각 블록의 첫 30/43개 5분 샘플을 사용했다. 2가지 항로 길이 × 고정/실측 소비량 × 5개 동일 가격 시드 × 4전략 = 9,600회 실행. 가격 시드는 독립적인 소비 데이터가 아니며 고정 소비 대조군은 블록 간 중복 조건이다.

소비량은 실측 kg/s ÷ 학습 구간 평균 kg/s × 0.05로 정규화했다. 실제 탱크 용량이나 실제 항해시간을 추정한 것이 아니다. 미래 실측 소비량은 정책 입력에 제공하지 않았다. 기존 정책 관측과 가중치는 그대로이고 다음 환경 전이에만 실측 소비량을 적용했다.

기존 환경은 소비 후 급유하며 부족분을 0으로 잘라낸다. 따라서 원래 도착 판정 외에 급유 전 미충족 소비량이 없는지를 확인하는 엄격 성공률을 추가했다. 원래 실행은 보존하고 부족 발생 이후에도 원래 종료 조건까지 기록했다.

## 결과: 실측 소비량에서 엄격 성공률
|선박|독립 블록 수|DQN 30/43단계|SafeStock 30/43단계|
|---|---:|---:|---:|
|Poseidon|73|100% / 100%|46.6% / 46.6%|
|Triton|17|100% / 100%|100% / 100%|
|Ceto|30|100% / 100%|90.0% / 90.0%|

고정 소비 대조군에서는 DQN과 SafeStock 모두 100%였다. 특히 Poseidon의 기존 도착 판정은 SafeStock도 100%였으나, 급유 전 부족분을 검사하면 46.6%로 내려간다. 이는 실제 해난 확률이 아니라 이번 합성 환경의 판정 차이다. 블록 앞부분만 사용한 제한적인 검증이므로 전체 운항 데이터에 대한 일반화 주장은 하지 않는다.

상호 성공한 동일 사례에서 DQN의 잔여 연료 가치 보정 비용지수는 SafeStock보다 0.21~0.61% 높았다. 원래 구매비용지수도 17.42~37.89% 높았다. 따라서 안전성 스트레스 검증에 유용하지만 비용 절감 효과는 확인하지 못했다. 실패 사례의 낮은 구매비를 절감으로 계산하지 않았다. 비용은 실제 통화가 아닌 합성 지수다.

## ONS 반영 범위
원본 2,076행을 기존 파서로 검증하고 미래 주차를 쓰지 않는 과거 누적 평균 대비 통항량 비율을 계산했다. 원본 마지막 Suez 화물선 관측(2024-04-01)은 49회, 과거 평균 대비 0.327배였다. 희망봉 화물선의 마지막 관측은 2024-03-25로 날짜가 다르며 비율은 2.399배였다. 이 비율은 계절성을 보정한 인과효과나 현재 상황이 아니다.

30→43단계는 프로젝트에 있던 SCA 대표 항로 거리 8,288→11,755해리 가정에서 나온다. ONS 통항 감소율을 지연시간이나 연료량으로 변환하지 않았다. FuelCast에는 ONS와 연결할 공통 선박·달력 날짜 키가 없어 두 데이터를 실제 동일 항해로 결합하지 않았다. ONS는 시나리오 맥락, FuelCast는 소비 변동 검증이라는 역할로 함께 보관한다.

## 반영 결정
- FuelCast: 외부 평가용 연구 모듈과 검증 데이터로 채택. 공식 학습 데이터 편입·새 모델 성능 향상 주장은 보류.
- ONS: 항로 통항 관측 및 대표 우회 시나리오 설명 자료로 채택. 예측 입력으로 추가했을 때의 성능 이득은 이번 실험으로 측정하지 않음.
- 본편 README·논문·서비스와 공식 체크포인트는 이번 실험 결과로 변경하지 않음.

## 재현
ZIP을 풀고 부모 디렉터리에서 `PYTHONPATH=/tmp/bunker-eval:/tmp/bunker-gym python ons-fuelcast-pilot/run.py` 실행. 경로는 설치 환경에 맞게 조정. Python 3.12, pandas 2.2.3, NumPy 2.5.3, PyTorch 2.14.1+cpu, Gymnasium 1.3.0 사용. 입력 CSV, 기존 환경/전략/에이전트 소스, 체크포인트를 포함한다. FuelCast 파생 입력의 이용 범위는 함께 넣은 원본 데이터 카드를 따른다.

검증: 9,600개 결과 키 중복 없음, 엄격 성공이 원래 성공을 초과하지 않음, 체크포인트 SHA-256 일치. 전체 수치와 조건은 summary.csv, paired_costs.csv, manifest.json에 기록.
