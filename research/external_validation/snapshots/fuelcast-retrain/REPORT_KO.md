# FuelCast 재학습 비교 결과 — 공식 모델 교체 보류

## 결론
실험 환경의 급유 전 연료 부족 판정을 수정하고 기존 DQN을 FuelCast로 추가 학습했다. 3개 학습 시드 모두 최종 평가에서 기존 DQN과 동일한 성공률을 보였지만 잔여 연료 가치 보정 비용이 개선되지 않았다. 공식 모델은 유지하고 이번 후보는 보류한다. FuelCast의 외부 스트레스 검증 활용 결정은 유지한다.

## 비교 결과
각 모델은 동일한 120개 소비 블록 × 2개 항로 길이 × 5개 가격 시드 = 1,200회 평가했다. 기존 DQN, SafeStock, 재학습 3개 모델을 합쳐 6,000회다. 성공은 급유 전 연료 부족 없이 도착하는 기준이다.

|모델|성공률|30단계 보정 비용 변화|43단계 보정 비용 변화|
|---|---:|---:|---:|
|기존 DQN|100%|기준|기준|
|재학습 seed 41|100%|+0.069%|+0.225%|
|재학습 seed 42|100%|+0.003%|+0.179%|
|재학습 seed 43|100%|+0.085%|+0.234%|

비용 변화는 기존 DQN 대비이며 양수는 비용 증가다. 보정 비용은 구매 SCI − 종료 시 잔여 연료 가치 + 시작 연료 가치다. 실제 통화 지출이 아닌 합성 지수이고 종료 가격으로 재고를 평가한다. 원래 구매비용도 seed 42의 43단계(-0.249%) 한 조건을 제외하면 증가했다. 일부 원래 구매비 감소만으로 개선이라고 판단하지 않았다.

SafeStock은 Poseidon 46.6%, Triton 100%, Ceto 90.0%였고 전체 사례 기준 65.0%다. SafeStock과 기존 DQN이 함께 성공한 사례에서 SafeStock의 보정 비용이 약 0.31~0.48% 낮지만, 실패 사례를 제외한 조건부 비교이므로 전체적으로 더 좋은 전략이라는 뜻은 아니다.

## 학습 및 선택
- 기존 공식 가중치에서 추가 학습, Adam 옵티마이저는 새로 시작. 6개 기존 관측·기존 네트워크·행동 공간 유지.
- 시드 41·42·43 각각 1,500 에피소드, 총 4,500 에피소드. 학습률 0.0001, 할인율 0.99, 배치 64, 4전이마다 업데이트, 500전이마다 타깃 동기화.
- 기존 시간순 학습/검증/평가 분리 및 288개 인덱스 간격 유지. 학습 블록 358개, 검증 117개, 평가 120개. 선박은 학습 시 동일 확률로 선택.
- 매 500 에피소드마다 검증. 선박별 성공률 평균을 먼저 최대화하고 동률이면 성공 사례의 선박별 평균 보정 비용을 최소화. 시드별 선택 에피소드는 41: 1,500 / 42: 500 / 43: 1,000.
- 평가 데이터로 체크포인트를 선택하지 않았음. 다만 해당 평가 구간은 앞선 실험에서 이미 확인한 구간이므로 새로운 맹검 외부검증으로 주장하지 않음.

## 환경 수정
연료 소비가 급유보다 먼저 일어난다는 기존 순서를 유지했다. 단계 시작 재고가 필요한 소비보다 부족하면 그 단계의 급유를 실행하지 않고 실패로 종료한다. 기존처럼 소비 부족을 0으로 잘라낸 뒤 급유로 복구시키지 않는다. 부족 상황에서 급유 액션으로 살아나는 경우와 충분한 재고에서 정상 급유하는 경우를 검증했다. 이 수정은 별도 실험 환경 StrictEnv에 적용했다.

학습 보상은 구매 SCI/650,000의 음수, 종료 재고 가치의 양수, 실패 시 -50으로 설정했다. 비용 개선을 목표로 보상과 종료 조건을 함께 바꿨으므로 결과 차이를 FuelCast 데이터 하나의 인과효과로 해석할 수 없다. 실제 재고·항해시간을 가진 운항 시뮬레이터가 아니며, 5분 실측 소비 변동을 정규화된 30/43단계에 재생했다.

## ONS와 프로젝트 반영
ONS는 기존 30/43단계 대표 항로 스트레스의 맥락 자료로 유지했다. 통항량을 실제 지연시간으로 환산하거나 FuelCast와 같은 항해로 결합하지 않았고, 재학습 관측에도 추가하지 않았다. 공식 모델·서비스·논문 성능표는 교체하지 않았다.

## 보관 및 확인
이 보고서와 비교 CSV는 `02 실험결과 / 02 연결 보류·검토`에 보관한다. 체크포인트·원본 입력·코드는 `06 학습모델재현`의 기존 연구 폴더에 별도 재현 ZIP으로 보관한다. 결과 폴더에는 코드·원본 데이터·모델을 넣지 않는다.

실행: ZIP을 푼 부모 폴더에서 Python 환경에 numpy, pandas, torch(CPU), gymnasium, pyarrow를 설치하고 `python fuelcast-retrain/run.py` 실행. 상세 버전은 manifest.json. 원본 데이터 이용 조건은 포함된 FuelCast 데이터 카드를 따른다.

검증: 공식 체크포인트 및 원본 데이터 SHA-256 일치, 평가 6,000행 조합 중복 없음, 학습 로그 4,500행, 부족 판정 회귀 점검 통과. 독립 소비 블록은 120개이며 가격 시드 반복을 독립 선박 표본처럼 해석하지 않았다.
