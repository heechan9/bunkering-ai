# 소비량 기반 안전재고 추가 검증

결론: 연구용 비교 전략 유지, 기존 DQN 교체 불가. 새 FuelCast 구간에서는 비용 이점이 재확인됐지만 갑작스러운 소비 증가에 대한 취약성이 드러났다. 이번 결과를 보고 규칙이나 여유분을 다시 조정하지 않았다.

## 고정한 조건과 새로운 평가
AdaptiveStock 규칙, 학습 구간 95분위 사전값, 최근 소비 3개 및 여유 0.02를 이전 구현 그대로 유지했다. FuelCast 각 288샘플 블록에서 이전에 사용한 앞 43개 대신 144~186번째(0-based) 43개를 사용했다. 앞선 평가 창과 겹치지 않는지 확인했다. 가격 시드는 830000~830004로 교체했다. 이는 같은 선박·같은 기존 평가 기간의 새로운 부분 구간이며 독립 외부 선박 검증이 아니다.

FuelCast 120개 창 × 2길이 × 5시드 × 3정책 = 3,600회. 별도로 소비 1.5/2/3/4배가 단계 5/10/15(0-based)부터 지속되는 합성 급변 시나리오 12종 × 2길이 × 20시드 × 3정책 = 1,440회. 총 5,040회.

## 결과
|평가|AdaptiveStock|기존 DQN|기존 SafeStock|
|---|---:|---:|---:|
|새 FuelCast 구간|100%|100%|선박·길이별 58.90~100%|
|소비 급변 합성 조건|83.33%|100%|58.33%|

새 FuelCast 구간에서 AdaptiveStock의 잔여 연료 가치 보정 SCI는 기존 DQN보다 선박·길이별 약 0.105~0.416% 낮았다. 원래 구매 SCI는 5.37~37.36% 낮았다. 실제 통화 절감이나 통계적 유의성을 주장하지 않는다.

급변 조건에서 AdaptiveStock은 단계 15부터 소비가 3배·4배로 증가하는 두 조건에서 실패했다. 나머지 10조건은 통과했다. 각 정책별 480회 중 AdaptiveStock은 400회, DQN은 480회, SafeStock은 280회 성공했다. 반복 가격 시드는 독립 소비 경로가 아니다.

## 해석
과거 소비를 보고 여유를 정하는 규칙은 아직 관측하지 못한 급증을 알 수 없다. 더 자주 재고를 유지하는 기존 DQN은 이번 급변 조건을 견뎠다. 평상 조건에서 더 낮은 재고·비용을 달성한 것만으로 더 우수하거나 더 안전하다고 판단할 수 없다.

새 전략은 과거 소비 관측과 선박별 학습 사전값을 사용하고 기존 DQN은 기존 6개 관측을 유지한다. 따라서 정보량까지 같은 알고리즘 비교는 아니다. 합성 급변의 배수·시점은 가정이며 특정 해외기관의 실측 자료를 뜻하지 않는다.

## 반영
연구용 비교 전략 구현은 연결 완료 상태로 유지한다. 실제 운영·공식 DQN 교체는 하지 않는다. 기존 성공 보고서와 함께 이 한계 보고서를 보관한다. 다음 개선을 하더라도 이번 평가 조건을 튜닝 대상으로 바꿨다는 점을 기록하고 다른 검증 구간을 남겨야 한다.

결과: summary.csv, paired_costs.csv, episodes.csv, failure_trace.csv. 5,040행 키 중복 없음, 이전 FuelCast 평가 창과 비중복 확인. 공식 모델 가중치 변경·재학습 없음.

재현: 기존 adaptive-stock-review-repro.zip을 먼저 풀고 이번 추가검증 ZIP을 같은 부모 폴더에 푼 뒤 python adaptive-stock-validation/run.py 실행. 기존 입력·환경·체크포인트를 그대로 사용한다.
