# 프랑스 해역·미국·일본 자료 도입 검토와 실행 결과
2026-10-03

## 적용 판단
공식 급유정책에 새 기능을 즉시 추가할 근거는 확보하지 못했다. 프랑스 해역 자료와 미국 가격 자료는 실행 가능한 연구용 입력으로 확보·파싱·비교했고, 일본은 공개 시험자료를 확보했으나 소비량 모델 실행에 필요한 입력/코드를 확보하지 못했다. 세 국가 기술 전부의 성능 실험 완료로 표현하지 않는다.

## 프랑스 해역: 브레스트 항로 식별 실험
원본: https://zenodo.org/records/6402160
제작기관: NATO STO CMRE. 프랑스 해역 데이터이며 ENSTA 제작물 아님.
17개 항로 prototype, 800개 tracklet(항로 내 400 / 항로 밖 400).
각 tracklet의 5개 위치와 항로 선분 간 평균 최단거리를 이용한 고정 최근접 기준모델 실행.
항로 내 400개에서 정답률 29.5%. 방향·시간을 사용하지 않아 반대 방향/겹치는 항로를 구분하기 어려운 기준모델이다. 항로 밖 판별 기능은 없으므로 전체 정확도라고 보고하지 않는다.
결론: 데이터는 항로 분석 연구에 활용 가능. 이 단순 분류기를 실제 항로 판정 기능에 넣을 수준은 아니다. 급유/항만 후보 정보를 제공하는 자료도 아니다.
라이선스: 원본 READ_ME의 CC-BY-NC-SA-4.0. 원본과 결과는 연구 보관용.

## 미국: EIA 과거 월별 가격 재고규칙 실험
https://www.eia.gov/dnav/pet/hist/LeafHandler.ashx?n=PET&s=EMA_EPPR_PTA_NUS_DPG&f=M
원본 HTML 및 XLS 확보. 추출된 실제 숫자는 1983-01~2011-02, 총 338개월. 페이지에 이후 연도가 보여도 값은 '-'이므로 2022년까지 데이터가 있다고 판단하지 않는다.
1984~2010의 27개 완전한 연도에 고정 월 수요 1,000gal, 탱크 2,000gal, 최초·종료재고 0, 보관·급유수수료 0 가정.
기준은 매월 필요한 양만 구매. 비교 규칙은 현재 월 가격이 이전 3개월 평균보다 낮으면 최대 다음달분까지 구매. 당월 가격을 알고 구매한다고 가정하며 미래 가격은 사용하지 않는다.
연도별 기준 대비 비용 변화 평균 +0.7448%(악화). 27개 중 12개 연도만 개선. 최선 -1.3886%, 최악 +6.8762%.
연도 말 같은 재고·총구매량 12,000gal 및 음수재고 없음 검증.
결론: 실제 역사 가격 경로는 유용한 연구 입력. 해당 단순 구매 규칙은 추가할 가치가 확인되지 않았다. 국가 평균 중유 판매가격이며 항만별 벙커유 가격이 아니다. 월별 자료를 시간별·일별 가격으로 축약 대입하지 않았다.

## 일본: NMRI JBC 및 OCTARVIA
https://t2015.nmri.go.jp/jbc.html
https://t2015.nmri.go.jp/jbc_gc.html
https://t2015.nmri.go.jp/Presentations/Day1-AM2-JBC-TestData1-Hirata.pdf
공식 선형·시험 설명과 수조시험 PDF 확보. 공식 페이지에 실제 실선이 존재하지 않는다고 명시. 선형·저항·추진 검증용이며 관측 연료 kg/s, 엔진 연료지도 및 우리 선박 교정값 없이 연료소비 모델로 대입할 수 없다.
OCTARVIA https://cloud.nmri.go.jp/portal/pub/octarvia
서비스 기능은 확인했지만 실행권한·필요 입력자료 확보 또는 API 호출 성공을 확인하지 못했다. 따라서 일본 연료소비 성능 실험은 미실행. JBC 시험자료를 확보한 사실을 API 도입 완료로 바꾸지 않는다.

## 그 외 후보의 상태
NOAA AIS: 공식 저장소 https://github.com/ocm-marinecadastre/ais-vessel-traffic 의 공개 데이터 경로를 확인. 이번에는 미국 AIS 원본을 내려받아 시험하지 않았다. 브레스트 자료와 비슷한 항로 분석 역할이며 미국 해역 일반화 검증은 남아 있다.
ENSTA: 연구 소개를 확인한 단계. 실행 가능한 공개 구현·입력 세트를 이번에 확보하지 못했으므로 성능 실험 미실행.

## 결론과 한계
미국·프랑스 입력 파서와 기준 실험 코드는 run_experiments.py로 재실행 가능. 해당 정책·분류기는 공식 프로젝트에 적용 보류. 일본 자료는 참고문헌으로 보관.
DQN·선박 물리모델·항로·미국가격을 하나의 실선으로 합친 실험이 아니다. 서로 다른 국가·시기·단위의 자료를 동일 항차 기록으로 결합하지 않았다.
GitHub main, 공식 모델, 제출논문 및 웹은 변경하지 않았다. 성능이 확인되지 않은 기능을 배포하지 않고 연구자료로 보관한다.
