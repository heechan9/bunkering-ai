# FuelCast 초기 예측 실험 — 2026-10-03

판단: 후속 연료소비 모델 연구에 사용할 가치가 있다. 환경 변수를 더한 모델은 3척 중 2척에서 속도 전용 모델보다 MAE가 낮았지만, 1척에서는 나빠졌다. 공식 급유정책 개선 또는 실선 적용 효과를 입증한 실험은 아니다.

| 선박 | 학습 평균 MAE | 속도 전용 MAE | 속도+환경 MAE | 속도 대비 오차 변화 |
|---|---:|---:|---:|---:|
| CPS_Poseidon | 0.50614 | 0.08582 | 0.09179 | +7.0% |
| CPS_Triton | 0.04445 | 0.02143 | 0.02024 | -5.6% |
| OSS_Ceto | 0.06119 | 0.06121 | 0.05366 | -12.3% |

오차 단위 kg/s, 낮을수록 좋음. 환경에는 기상·해양 변수와 수심이 포함된다. 모든 결과는 같은 시험행끼리 비교했다. RMSE는 metrics.csv 참조.

## 실험 설계
- 선박별 index 순서로 60% 학습 / 20% 검증 / 20% 시험. 무작위 행 분할 없음.
- 각 경계 이전에 288 index 단위(카드의 5분 간격 기준 24시간) 구간 제외.
- 시간 index 결측 12행 제외(Triton 4, Ceto 8). 나머지 index 중복 없음 확인.
- 학습 평균 기준값, 속도 전용 HistGradientBoosting, 속도+환경 HistGradientBoosting 비교.
- 반복 100회, learning_rate 0.08, L2 1, seed 42. 잎 수 7/15 중 검증 MAE로 선택. 시험셋은 선택에 미사용.
- 학습 시 소비량 구성요소·엔진 연료 유량·정답 대체 열을 입력하지 않았다. 시간 index도 입력하지 않았다.
- 음수 예측은 0으로 제한. 특성 결측은 모델의 내부 결측 처리를 사용. 원본 데이터 변경 없음.

## 프로젝트 연결 판단
1. Triton·Ceto에서는 환경 변수의 추가 효용이 관찰돼 연구를 이어갈 근거가 있다. Poseidon은 속도 전용이 더 나아 선박별 검증이 필요하다.
2. 현재 급유 환경의 0~1 재고와 합성 step에 kg/s 예측을 그대로 넣을 수 없다. 시간길이·탱크용량·초기잔량·보급 규칙을 명시한 별도 물리 단위 환경이 필요하다.
3. 이 데이터의 동시점 환경정보를 이용한 소비율 추정이며 미래 기상 예측 실험이 아니다. 사후 기상자료를 과거 의사결정 당시 알았다고 간주하지 않는다.
4. 단일 시간분할의 탐색 실험이다. 신뢰구간·계절별 재검증·다른 선박 일반화·급유정책 비용효과는 미검증. 한바다호로의 전이 성능을 주장하지 않는다.
5. 제출 논문·공식 모델·GitHub main·웹 배포는 이번 실험으로 변경하지 않았다.
