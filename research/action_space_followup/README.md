# NTNU 기존 후보 재평가와 5/6행동 비교 학습

2026-10-07. 기존 보관 자료를 사용한 연구이며 신규 외부 자료 수집·실선 실증은 아니다. 공식 모델·웹은 변경하지 않았다.

## 1. 기존 6,000에피소드 후보 재평가

보관 원자료, retrain.py, 3개 가중치, 분할 manifest의 SHA-256을 기존 audit.json과 대조했다. 원 함수 AST를 사용해 항차를 재구성했고 manifest가 기존 기록과 정확히 일치했다. 3,052조건 × 3시드의 비용·안전·시간 충족 여부를 기존 episodes.csv와 대조했다. 최대 비용 절대 차이는 4.66e-10, 안전·시간 판정은 일치했다.

각 항차의 5^4 / 6^4 행동열을 전수 계산했다. 비용 최소값과 별도로 학습 목적값(정규화 비용 + 시간 초과 패널티)의 최소값도 계산한다.

- 기존 5행동의 최선 비용이 LP보다 높은 조건: **70/3,052**.
- 3시드·전체 용량 가능 조건을 합산한 비용 차이 중 행동공간 제한 비중: **0.3286%**.
- 나머지 99.6714%는 비용 기준 행동 선택 차이. 시간 패널티라는 다른 목적도 있으므로 전부를 학습 실패로 단정하지 않는다.
- 6행동의 전수 최선은 LP와 최대 6.98e-10 차이로 일치.

분해식은 DQN−LP = (5행동 최선−LP) + (DQN−5행동 최선). 여기서는 시간 초과 조건도 포함한 **비용 전용 분해**이다. 아래 공통 시간충족 사례 비용과 분모가 다르다. 세 시드가 같은 항차를 공유하므로 독립 9,156항차로 해석하지 않는다. 이전 합성 120조건의 42건을 실제 NTNU 발생 빈도로 확대하지 않는다.

## 2. 동일 예산 비교 학습

새 5행동·6행동 모델을 시드 42/43/44 각각 2,000에피소드 학습했다. 기존 6,000에피소드 모델과 직접적인 개선율 비교가 아니다. 기존 train/validation/test/WAF 분할을 그대로 사용했다.

- 공통 12입력·64×64 은닉층, 기존 optimizer/replay/target/보상/시간 패널티 유지.
- 6행동은 기존 5개에 다음 저가항까지 필요한 양을 구매하는 행동 추가.
- 양쪽 epsilon 일정은 1,500에피소드 기준으로 0.05까지 감소. 500에피소드마다 검증 목적값으로 체크포인트 선택. 테스트로 모델을 선택하지 않았다.
- CPU 단일 스레드·결정론 연산 설정. 동일 시드지만 출력층 크기가 달라 초기 가중치/난수 소비가 완전히 같은 결합 실험은 아니다.
- 6모델 총 12,000학습 에피소드, 18,312평가 행. PyTorch 2.14.1+cpu.

공통 안전·시간 충족 사례의 **6행동 비용/5행동 비용−1**. 음수는 개선이다.

| 평가 | 시드42 | 시드43 | 시드44 | 시드별 공통 사례 |
|---|---:|---:|---:|---:|
| 내부 평가 | -0.07059% | -0.08314% | -0.11298% | 2,094/2,160 |
| 외부 WAF | +0.09722% | -0.27522% | -0.72630% | 737/892 |

안전율은 모두 100%이며 구조적 가드가 기여한다. 시간포함 성공률은 두 행동공간 모두 내부 96.9444%, 외부 82.6233%로 같았다. 외부는 기존 용량 불가능 8조건을 제외한 892조건이다. 효율 3가정을 묶은 표이며 서로 다른 효율·선형이 항로를 공유한다.

6행동도 공통 사례에서 LP 대비 내부 0.01255~0.07841%, 외부 0.05206~0.51592% 비싸다. 정적 가격 조건의 저가항 규칙/LP 우위를 뒤집은 결과가 아니다. 유의성·신뢰구간은 주장하지 않는다. 기존 평가 항로를 연구 방향 선택에 이미 사용했으므로 이번 반복 비교를 새로운 독립 확인 시험으로 부르지 않는다.

## 3. 결정

**6행동은 연구 후보로 유지하고 공식 모델 교체는 보류한다.** 내부 3시드 개선만으로 외부 일반화 성공을 선언하지 않는다. 다음 우선순위는 시간 패널티와 비용 목적의 선택 차이를 별도로 확인하고, 정책이 저가항 행동을 선택하는 상황을 분석하는 것이다. 실패한 외부 시드를 보고 하이퍼파라미터를 고른 뒤 같은 테스트로 최종 성능을 주장하지 않는다.

## 재현

기존 NTNU 재학습 보관 ZIP을 별도 폴더에 해제한 뒤:

```bash
python research/action_space_followup/run.py --archive /absolute/path/to/ntnu-existing
python research/action_space_followup/summarize.py
python -m unittest discover -s research/action_space_followup -p 'test_*.py' -v
```

Python 3.12, PyTorch, NumPy, pandas, SciPy 필요. 결과 폴더가 이미 있으면 run.py는 중단하며 덮어쓰지 않는다. 재실행은 결과를 별도 보관한 새 체크아웃에서 한다. 테스트는 시간 패널티를 포함해 벡터화 전수 계산을 독립적인 스칼라 전수 계산과 대조했다(1 passed). 재평가·분해식·정책 대응 검산 통과. 전체 저장소 회귀검사는 실행하지 않았다.

공개 가능 산출물은 코드·집계·실행 조건이다. 원자료·가중치·행별 결과는 별도 비공개 묶음으로 보관한다. execution.json, effective_train.py, 해시 목록으로 실행을 추적한다.
