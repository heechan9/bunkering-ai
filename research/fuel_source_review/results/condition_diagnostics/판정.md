# 조건별 소비·출력 오차 검토 — 2026-10-05

## 판정

선박1 출력 모델은 후속 연구 후보로 유지하되, 이번 검증 기준에서는 기준선 교체를 승인하지 않는다. 선박3 출력·소비 및 선박1 소비 후보도 교체 기준을 통과하지 못했다. 기존 DQN·운영 모델·실제 연료절감 주장은 변경하지 않는다.

가장 중요한 추가 발견: 선박1 259,503행과 선박3 264,175행에서 풍속·풍향이 모두 0이다. 실제 무풍으로 확정할 수 없고 기상 영향 검증에 쓸 수 없다. 선박3 흘수도 선수12.0m·선미13.2m로 전체 기간 일정하여 흘수 변화 효과를 검증할 수 없다. 4입력 MLP의 실제 변동 입력은 선박1에서는 속도·평균 흘수, 선박3에서는 속도뿐이다.

## 실행 결과

저장된 출력 모델6개와 소비 모델2개를 그대로 읽어 기존 시간순 분할을 재구성했다. 원래 테스트 MAE는8개 모델 모두 허용오차0.0001 내에서 재현됐다. 재학습은 하지 않았다.

|---|---:|---:|---|
|선박1 출력 MLP,3시드|5.12~8.01% 개선|7.99~15.39% 악화|기간 간 개선 일관성 부족|

|선박3 소비 모델|1.91% 개선|67.40% 악화|교체 보류|

여기서 비교 기준은 같은 선박·같은 구간의 비음수 속도³ 회귀다. 출력 kW와 소비 L/h의 오차를 서로 합산하지 않는다.

선박1 출력의 조건별 상세:
- 테스트 속도 상위 구간(14.09kn 초과,72개10분 기록)은 시드42/43에서9.96%/6.17% 개선했지만 시드44에서는3.16% 악화했다.
- 가장 낮은 흘수 구간(7.075m 이하,132개 기록)은10.86~14.33% 개선, 가장 높은 구간(7.345m 초과,79개)은1.05~5.56% 개선했다. 서로 다른 속도·흘수·운항 상태가 섞여 있으므로 흘수의 인과 효과는 아니다.
- 테스트7일 중6일은3시드 모두 MAE 개선. 2017-10-29는 시드44에서4.39% 악화했다. 시드와 날짜는 독립 선박 표본이 아니다.
- 학습 조건을 벗어난28개 기록의 MAE는257.71~264.30kW로, 조건 안606개 기록의116.75~120.79kW보다 컸다. 이28개에서도 기준선보다는 좋았으므로 영역 밖이라는 사실만으로 상대 성능 악화를 단정하지 않는다.

## 보류 규칙 시험

조건 구간 경계는 학습 데이터 사분위수로 고정했다. 입력 허용 범위는 학습 최소~최대값 및 학습 자료로 정한5번째 최근접 거리95분위수를 함께 사용했다. 시간상 바로 옆 표본의 유사성을 완화하기 위해 참조점을 학습10분 기록에서6개마다 하나 뽑았으나, 운항 공백 때문에 정확한 매시 표본이라는 뜻은 아니다.

학습 조건 안 검증 표본이30개 이상이고 해당 검증 구간 MAE가 기준선보다 작을 때만 후보를 허용하는 규칙을 적용했다.8개 모델 모두 두 번째 조건을 통과하지 못했다. 따라서 자동 후보 채택률은0%다. 이 결과가 기존 예측값 전부 무효 또는 안전한 운항 기준 확립을 뜻하지 않는다. 검증 구간의 선택·시계열 상관과 이전 테스트 열람 이력이 있어 사후 연구 진단으로만 사용한다.

검증 오차90분위수로 만든 대칭 오차범위의 테스트 포함률은 선박1 출력 약89.6~91.5%, 선박3 출력61.8~63.6%였다. 분포 변화가 있는 선박3에서 오차범위가 충분하지 않다. 이는 보장된 신뢰구간이나 검증된 conformal 예측구간이 아니다.

## 한바다 적용 가능 범위

기존7개24시간 기록에서 앞4개 학습 속도 범위는10.25~14.86kn. 뒤3개 테스트 중2개는 범위 안,1개는 밖이었다. 정렬된 풍속·흘수·대수속력 입력이 없어 DataBio의 전체 입력 보류 규칙을 이식할 수 없다. 한바다 평균속도와 DataBio 대수속력도 같은 측정 정의로 취급하지 않는다.7개 일별 기록만으로 일반화된 소비 예측 허용 범위나 실측 절감률을 확정하지 않는다.

## 다음 판단

외부 데이터 추가보다 독립된 다른 기간·항차에서의 재검증이 필요하다. 선박1은 출력 예측 연구 후보, 선박3 및 소비 모델 교체는 보류. 기상·흘수 가변성 부족을 메타데이터에 기록하고, 0값을 실제 무풍이라고 해석하지 않는다. 시험 구간에서 유리한 속도 경계를 골라 채택 규칙을 바꾸지 않는다.
