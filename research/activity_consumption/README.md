# 비공개 실선 자료의 활동별 검토

공개본은 방법과 한계만 설명합니다. 실제 수치·셀 근거·해시는 비공개 보관하며 공개 JSON/CSV는 비공개 전환 안내만 제공합니다. 이전 공개 결과를 재생성하던 CLI는 비공개 자료의 재게시를 막기 위해 중지했습니다. 분석은 비공개 작업공간에서만 수행합니다.

질량과 부피는 직접 합치지 않으며 활동 구분과 동일 구간 측정 여부가 확인되지 않으면 소비율·정책 성능을 추정하지 않습니다.

## 다음 자료 요청에 포함할 항목

- 각 기록의 실제 시작·종료 시각과 시간대, 소비량과 같은 집계 구간인지 여부
- 해당 구간의 정박·항해·작업 구분; 혼합 구간이면 실제 구간별 소비 계측 가능 여부
- 기관별 기록과 선박 총량의 포함 관계, 누락·중복 여부
- kL 측정 기준 온도와 연료 밀도, 측정 방식
- ROB 차감 외 독립 소비 계측 여부

이 목록은 요청 초안이며 제공기관에 전송하지 않았다. 원본 비공개 조건을 유지한다.
