# 한바다호 공개 집계에 활동별 검토 적용

2026-10-04. 프랑스 Ifremer의 활동별 기록 분석 관점을 현재 확보된 공개 집계에 적용한 결과이다.

| 입력 | 관측 집계 | 활동·시간 | 결과 |
|---|---|---|---|
| ROB 차감 요약 | 195.2 t | 미확인·추정 시간 | 소비율 산출 불가 |
| 일별 선택 셀 합 | 약 228.9 kL | 정합성 미확인 | 소비율 산출 불가 |

두 입력은 같은 항차의 서로 다른 표현이므로 별도 파일로 처리했다. 서로 더하거나 직접 비교하지 않는다. 195.2 t는 ROB 차감이며 독립 계측치가 아니다. kL 합은 기록된 셀의 부분 집계이며 완전성을 보장하지 않는다.

실행: `python research/activity_consumption/apply_hanbada.py`

기존 공개 `results/real_voyage/hanbada_review.json`에서 CSV를 만들고 검토기를 실제 실행했다. 원본 XLSX를 다시 분석한 것은 아니다. 각 결과에 입력 CSV 해시, 공개 집계 JSON 해시, 기존 검토가 기록한 원본 해시와 셀 근거를 남겼다. 생성 파일 4개는 이 스크립트로 재생성할 수 있다.

결론: 공개 집계 2개 연결, 활동별 유효 소비율 0개, 학습 편입 보류. 분류 자료 없이 정박·항해·작업 비율을 추정하지 않았고 모델을 재학습하지 않았다.

## 다음 자료 요청에 포함할 항목

- 각 기록의 실제 시작·종료 시각과 시간대, 소비량과 같은 집계 구간인지 여부
- 해당 구간의 정박·항해·작업 구분; 혼합 구간이면 실제 구간별 소비 계측 가능 여부
- 기관별 기록과 선박 총량의 포함 관계, 누락·중복 여부
- kL 측정 기준 온도와 연료 밀도, 측정 방식
- ROB 차감 외 독립 소비 계측 여부

이 목록은 요청 초안이며 제공기관에 전송하지 않았다. 원본 비공개 조건을 유지한다.
