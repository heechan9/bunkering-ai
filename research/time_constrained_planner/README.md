# 시간 제약을 포함한 급유 최적화 후보

2026-10-07. 요구·진행 승인: 최희찬. 구현·실행·분석: Codex.

## 결정

알려진 가격·수요를 사용하는 기존 NTNU 4구간 연구에서 6행동 DQN을 더 학습하는 대신, 안전재고와 시간 제한을 동시에 만족하는 최소비용 계획기를 구현했다. `planner.plan(c)`가 구매량·비용·시간을 반환하며, 충족 불가능하면 `None`을 반환한다. 이 경우 추천 가능한 계획이 없다는 뜻이며 실행을 진행해서는 안 된다.

**현재 근거는 연구용 결정론적 계획기 채택을 지지한다. 운영 DQN 교체 검증은 완료되지 않았다.** 운영 모델은 미래 가격을 모두 아는 이 연구와 입력·문제 정의가 다르며 연결 코드도 이번 변경에 포함하지 않는다. 본 계획기는 실제 선박 실증 또는 불확실한 가격·수요 상황의 우월성을 입증하지 않는다.

## 구현

연속 구매량과 이진 급유 정차 변수를 사용하는 혼합정수 선형계획. 초기 연료 0.5, 안전재고 0.1, 탱크 용량 1, 모든 항구 공급 가능 조건이다. 각 구간 출발 전 용량과 도착 후 안전재고를 제한한다. 항해시간, 급유 고정시간, 구매량 비례 급유시간 합에 마감시간을 강제한다. 비용은 기존 실험과 동일한 최저가격 기준 잔량 정산이다. 목표 상대 최적성 간격은 0이며 수치 허용오차 내 최적해를 사용한다.

학습·시드 선택 없이 입력 조건으로 계산한다. 고정된 항로에 대한 계획이며 경로·속도 변경 기능은 없다. 예상 실패는 불가능 반환, 예상하지 못한 솔버 실패는 예외로 처리한다.

## 기존 데이터 재평가

원본 archive의 체크섬과 경로 manifest를 확인하고 용량상 실행 가능한 3,052개 조건을 평가했다. 아래 비용은 두 방법 모두 안전·시간 조건을 만족하는 동일 사례들의 총비용 비교다. 비교 DQN은 이전 6,000회 학습 모델 3개이며, 직전 2,000회 파일럿과 다른 비교다.

| 평가 | 사례 수 | 양쪽 충족 사례 | DQN 대비 비용 감소 (시드 42 / 43 / 44) |
|---|---:|---:|---|
| 내부 | 2,160 | 2,094 | 0.0651% / 0.0731% / 0.0421% |
| 외부 | 892 | 737 | 0.2243% / 0.2685% / 0.1581% |

모든 공통 충족 사례에서 개별 비용도 기존 DQN 이하임을 검사했다. 저가항 규칙 및 기존 비용 전용 LP와 총비용은 같았다. 시간 준수 사례 수 증가도 없었다. 따라서 최적화기를 기존 저가항 규칙보다 더 경제적이라고 주장할 수 없다. 새 구현의 추가 기능은 시간 제약의 명시적 처리와 불가능 판정이다.

기존 테스트를 재사용한 개발 평가이며 새 독립 holdout이 아니다. 효율 가정·선박 크기별 행은 독립 실측 표본이 아니다. 비용 감소는 이 합성 환경에만 해당하며 실선 절감률이 아니다. 조건별 원자료·경로·가중치는 공개하지 않는다. 집계는 `summary.json`에 기록한다.

## 검증 및 실행

```bash
python -m unittest discover -s research/time_constrained_planner -p 'test_*.py'
python research/time_constrained_planner/evaluate.py --archive /path/to/extracted/archive
```

테스트 4개 통과: 30개 무작위 조건에서 별도 16개 정차 조합 LP 열거 결과와 일치, 불가능한 구간·항해시간 처리, 잘못된 입력 거부, 촉박한 마감에서 정차를 한 번으로 합쳐 실행 가능한 계획 생성. 평가에는 NumPy/Pandas/SciPy/PyTorch와 기존 `action_space_followup/run.py`가 필요하다. 계획기 자체는 NumPy/SciPy만 사용한다. 전체 저장소 회귀 테스트는 이번 변경에서 재실행하지 않았다.

시간 불가능 원인: 외부 155건 모두 항해시간 자체가 마감을 초과했다. 내부 66건 중 54건은 항해시간 초과이고, 나머지 12건은 급유까지 포함하면 충족 불가능했다. 고정 항로·속도 조건에서 급유 정책 교체만으로 이 실패를 해결할 수 없다.
