# EMSA THETIS-MRV 원본 확보 및 적용 판정

2026-10-05 공식 공개 API에서 2024 v246, 2025 v59 XLSX를 직접 확보했다. 두 파일의 생성일은 2026-10-01이다. 원문: https://mrv.emsa.europa.eu/#public/emission-report

## 실행 결과

| 보고연도 | 전체기간 보고 행 | 일부기간 보고 행 | 전체기간 중 연료·해상시간·거리당 소비 모두 양수 숫자인 행 |
|---|---:|---:|---:|
| 2024 | 14,174 | 1,027 | 12,959 |
| 2025 | 17,346 | 1,532 | 15,282 |

각 시트는 113열이다. 전체기간 시트의 연료소비 0인 행은 각각 1,206 / 2,052행이다. 0값과 N/A, Division by zero! 등의 비수치값을 유효 소비 관측으로 간주하지 않았다. 양수 숫자 필터는 참고 통계의 최소 조건이며 정확성 인증이 아니다. 전체기간과 일부기간 보고서를 더하지 않는다. 선종별 중앙값·IMO 중복·해시·원본 URL은 audit.json에 기록했다.

## 프로젝트와의 대응

| 항목 | 기존 소비 후보 모델 | EMSA 원본 | 판정 |
|---|---|---|---|
| 시간 단위 | 10분 집계 시계열 | 보고연도/일부기간 집계 | 직접 비교 불가 |
| 목표 | 주기관 소비 L/h | 총연료소비 m tonnes, 거리당 kg/n mile | 장치 범위·단위 다름 |
| 입력 | 대수속력·흘수·풍속 | 동시 측정 입력 시계열 없음 | 기존 모델 추론 불가 |
| 선박 | DataBio 어선·한바다호 검토 | 여러 상선 선종의 IMO | 선종별 참고 통계 가능 |
| 급유 검증 | 사건별 공급·ROB 필요 | 공급 사건·ROB 시계열 없음 | 급유 의사결정 실증 불가 |

채택 범위: 외부 선종별 연간 소비·거리당 소비 참고자료 및 데이터 품질 검토.
보류 범위: 기존 모델 정확도 비교, DQN 재학습, 운영 모델 교체, 실제 연료절감률 주장.
연간 총연료를 해상시간으로 나누어 주기관 순간 소비인 것처럼 쓰지 않는다. 연료소비/거리당소비로 역산한 거리·속력을 입력으로 되먹이는 목표값 누출도 금지한다. MRV 보고 범위는 전 세계 모든 운항을 뜻하지 않는다.

## 재현

Python + pandas + openpyxl + requests 필요. `download.py`로 고정 버전 원본을 내려받고 `audit.py`를 실행한다. 최신판 자동 교체 없이 고정 버전과 SHA-256을 사용한다. 원본은 별도 보관하며 저장소에는 검산 코드와 집계 결과만 둔다.

```bash
python research/emsa_mrv/download.py
python research/emsa_mrv/audit.py
```

출처 설명: https://www.emsa.europa.eu/thetis-mrv.html

선명 검색의 HANBADA 일치 기록은 IMO 9869203의 **HMM HANBADA(Container ship)**다. 한국해양대 실습선과 이름 일부가 겹치는 상선이므로 연결하지 않는다. 2025년 전체기간·일부기간에 같은 소비량이 나타나는 사례도 있어 단순 합산하지 않는다.
