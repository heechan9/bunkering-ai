# 영국 연구 관점 적용 — 합성 비교 결과 (2026-10-04)

판정: 독립 연구 평가 도구로 구현·실행 완료. 공식 정책 교체 보류.
Aydin 등(2017)의 항만 지연·선속 관점, De 등(2021)의 가격·소비 불확실성 관점을 참고했다.
원문 동적계획법·최적화 정책을 재현한 것이 아니다. De 원문 전체 수식은 미확인(저장소 재조회403).
서지와 링크: ../../docs/technical/uk_bunkering_application.md

실행: python research/uk_bunkering/experiment.py
출력: results/episodes.csv (9600행), results/summary.json (48조합, 코드 SHA-256).
실행은 해당 결과를 갱신한다. Python 표준 라이브러리만 필요하며 인코딩은 UTF-8로 명시했다.

## 방법과 제한

8개 구간, 구간거리100 합성 거리단위, 속도10/12 거리단위/시간, 마감112시간.
초기재고50, 용량120, 예비재고15 합성 연료단위. 출항 전 구매 후 소비하는 별도 환경이다.
공식 환경과 전이 순서가 다르므로 기존 DQN 결과와 비교하지 않는다.
소비는 기준20 × (속도/10)^2 × 변동배율. 선박 물리 보정값이 아니다.
U0 고정; U1 가격만 Uniform(75,125); U2 소비배율만 Uniform(.7,1.3); U3 둘 다.
가격·소비·처리시간은 독립 RNG. T0 서비스4시간; T1 Uniform(0,8)시간.
시드1000~1199의 200사례를 모든 정책에 동일 적용. 학습·사후 튜닝 없음.
가격100, 최대소비배율1.3과 평균처리시간4는 알려진 합성 분포 가정이다.
각 구간 실제 소비와 미래 가격·서비스시간은 정책에 사전 제공하지 않는다.

baseline: 예상 소비 + 예비재고까지 구매.
price: 현재 가격100 미만이면 탱크 채우기, 아니면 baseline.
buffer: price 정책의 예상 소비를 최대배율1.3으로 보수화.
fixed: 속도10. adaptive: 관측 누적시간과 남은 평균시간으로 마감 초과 예상 시12.
모든 정책에 동일한 구매 범위와 속도 선택지가 있으며 fixed는 속도10만 고르는 기준정책이다.
급유 자체의 시간·수수료, 상관 충격, 장애, 실제 항만별 가격구조는 없다.

purchase_cost_per_consumed_unit=구매비용/실제 소비량. 기존 프로젝트 SCI(누적 비용)와 다른 지표다. 잔량보정비용=구매비용+100×(초기재고−최종재고).
초기·최종 연료를 동일 고정가격100으로 평가하는 비교용 회계이며 시장 청산가가 아니다.
안전=모든 구간 예비재고 유지+완주. 지각률 분모=완주 사례. 연료부족이면 즉시 종료.
공통안전 비용은 같은 조건에서 6정책 전부 안전한 seed에 한정한다.
U3/T1 공통안전 사례는 2개뿐이므로 그 비용으로 절감률·우열을 일반화하지 않는다.

전체 9600건에서 연료 고갈은 없었다. 완주와 예비연료 유지는 별개다.

해석: 시간 반응 정책은 지각을 줄이지만 소비·비용을 늘린다. 상한을 아는 buffer의 안전성은
설계상 보장에 가까우며 실측 분포에서의 일반화 증거가 아니다. price의 잔량 때문에 구매비용만
비교하면 왜곡된다. 공식 교체는 하지 않고 연구용 진단 코드로 채택한다.

검증: 변동요인 분리, 질량수지·용량, 고정조건 수계산, 미래정보 미사용, 상한 내 안전성 6개 테스트.
기존 관련23개 포함29개 통과(Linux). 신규6개는 Windows 미실행. 실선 검증 및 재학습 없음.

## 후속 감사 반영

paired_safe.json은 같은 속도 정책에서 baseline-price, price-buffer 각각의 공통 안전 seed와 잔량보정 비용을 비교한다. 전체 6정책 공통안전 집계도 유지한다. 조건부 비교는 위험 사례를 제외하므로 전체 안전률과 함께 해석해야 한다.

U3/T1 price-buffer 공통안전 비교: 고정속도161건에서 buffer 보정비용 +0.0835%, 적응속도148건에서 +0.1560%. 전체 안전률은 각각 price 80.5%/74.0%, buffer 100%/100%. 이는 합성 상한 내 평가다.
