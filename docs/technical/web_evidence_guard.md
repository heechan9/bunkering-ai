# 웹 정본 대조 검사 (2026-09-21)

`python scripts/audit_web_evidence.py`는 저장소의 Ocean Lab 정적 재생 자료를 읽기 전용으로 검사한다. 팹가드의 정본-웹 대조와 적대적 AI의 오류 주입 검사 방식을 참고한 병커시유 전용 구현이다.

- 과거 웹 대조 기록의 replay SHA-256과 현재 바이트 일치
- 연구 CSV와 웹 summary의 정책/체크포인트 키 및 70개 수치 일치
- 출처 기록과 체크포인트 식별 해시 일치 (바이너리 모델 검증은 아님)
- 7개 정책/체크포인트 × 공유 사례 100개, 전이 19,030개
- 전이별 연료수지, SCI, 보상 성분 합, 원래 엄격 안전선 판정 재계산

불일치·누락 시 종료코드가 0이 아니며 파일을 자동 수정하지 않는다. 웹 결과나 정본 CSV를 변경할 때 GitHub Actions가 이 검사를 실행하도록 구성했다. 워크플로 추가는 원격 실행 통과 기록과 구분한다.

오류 주입 검사는 임시 복사본에 수치·체크포인트·사례 누락·안전선 flag 오류를 넣는다. replay 해시를 함께 갱신해도 내용 대조가 실패해야 한다. 원본 파일은 변경하지 않는다.

범위: 저장소에 보관한 재생 데이터와 정본의 일관성이다. 배포 화면의 DOM·반올림·실제 모바일 클립보드, 새 모델 추론, 실제 항차 성능 검증은 포함하지 않는다. 전체 전이 원본 묶음에서 웹 파일을 다시 생성하는 기능은 이번 범위가 아니다. 논문 v5.0·공식 결과·체크포인트는 그대로 유지한다.

현수 검토 확인: PR #44의 독립 코드 리뷰와 PR #48 보고서 정정 및 병합 이력을 확인했다. 이는 과거 버전에 대한 기록이다. 사용자는 새 요청도 수행했다고 전달했으나, 이번 v5.0/웹 점검의 별도 결과·대상 커밋·로그는 현재 확인하지 못했다. 과거 검토를 새 버전 승인으로 재사용하지 않는다.

구현·검사: Codex. 범위·진행 승인: 최희찬.

로컬 확인: 대조 검사 통과(70개 수치·700개 조합·19,030개 전이), unittest 4개 메서드 통과(정상 입력 및 9가지 오류 시나리오 포함). 표준 라이브러리만 사용하므로 새 Python 의존성이 없다.
