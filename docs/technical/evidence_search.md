# 공개 문서 근거 검색

WHSPIDER의 문서 검색 후 근거를 제시하는 아이디어를 참고하여, 병커시유에 필요한 로컬 원문 검색만 독립 구현했다. 참고 프로젝트: https://github.com/JKprokan/WebSpider-for-WebHacking
외부 코드·모델을 복사하거나 보안 크롤러를 연결하지 않았다.

## 실행

저장소 루트에서 Python 표준 라이브러리만으로 실행한다.

```sh
python scripts/search_evidence.py 'ONS는 어디에 사용됐어?'
python scripts/search_evidence.py 'FuelCast 모델 교체했어?'
python scripts/search_evidence.py '왜 DQN 구매비용이 더 높아?' --limit 3
```

JSON에는 원문 구절, 저장소 상대 경로, 1부터 시작하는 행 번호, 전체 파일의 SHA-256, 일치한 검색어가 포함된다. 긴 행은 900자로 잘라 `truncated: true`로 표시하므로 파일에서 전체 행과 문맥을 확인한다. 해시는 검색 당시 바이트를 식별하며 내용의 진실성을 보증하지 않는다.

검색 대상은 `scripts/search_evidence.py`의 `SOURCES`에 명시된 공개 문서 6개다. 외부자료 최종 결정, 안전회계, 4시드 진단·평가, 웹 근거 검사, 제출 상태를 포함한다. 과거 원고와 비공개 Drive 자료는 검색하지 않는다. 허용 파일 누락이나 저장소 밖 경로는 오류로 처리한다.

## 해석 범위

- 한국어 일부 조사·주제 별칭을 처리하는 키워드 검색이다. 의미 검색·LLM·RAG 답변 생성 기능은 아직 없다.
- 행마다 검색어가 2개 이상(검색어가 하나면 1개) 일치해야 반환한다. 일치 비율로 정렬하며 확률·신뢰도 점수는 제시하지 않는다.
- `matches`는 관련 구절 후보가 있다는 뜻이다. 질문의 전제나 결론을 검증했다는 뜻이 아니다. 단어가 겹치는 무관한 질문은 결과가 나올 수 있다.
- 없으면 `no_match`를 반환한다. 임의 답변·출처를 붙이지 않는다. 검색 결과가 없다는 사실이 자료 전체에 근거가 없다는 뜻도 아니다.
- 웹이나 공식 학습 경로와 연결하지 않는다. 외부자료로 모델 성능이 개선됐다는 주장을 만들지 않는다.

## 확인 방법

```sh
python -m pytest tests/test_search_evidence.py -q
```

실제 질문 3종의 원문·해시 일치, 빈 질문·미등록 주제 미응답, 긴 근거 보존, 변경된 해시, 저장소 밖 경로와 누락 파일 오류를 확인한다.
