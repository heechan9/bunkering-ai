# 실선 자료 검토 공개 범위

세부 운항 기록과 파생 수치는 공개본에서 제외했습니다. 원자료 및 상세 검토는 비공개로 보관하며, 공개본에는 단위·시간 정합성과 측정 독립성에 관한 방법 및 한계만 남깁니다. 실제 정책 성능이나 비용 절감의 검증 자료가 아닙니다.

자료 제공: 국립한국해양대학교 해기교육원 한바다호 AB-LOG. 원본 비공개 조건의 인용 허용을 공개 원자료 허용으로 확대하지 않습니다.

- 요약 잔량 차감과 독립 소비량 계측은 다릅니다.
- 질량과 부피 비교에는 밀도·기준 조건·시간 정합성이 필요합니다.
- 확정되지 않은 시각과 빈 값을 관측 사실로 채우지 않습니다.

2026-10-14 공개 최소화 조치. 과거 Git 이력·기존 복사본까지 삭제되었다는 의미는 아닙니다.
