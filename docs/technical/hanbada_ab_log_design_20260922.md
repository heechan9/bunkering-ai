# 한바다호 AB-LOG 검토 기능과 논문 v5.5

2026-09-22. 해기교육원이 논문을 검토할 수 있도록 출처 셀, 산술 확인과 해석 한계를 함께 기록한다. 원자료 제공은 연구 결과의 승인이나 정책 실증을 뜻하지 않는다.

## 자료와 확인 범위

김승현을 통해 받은 한바다호 AB-LOG의 파일 표기는 2026년 5월이다. 메시지에는 2025년이라고 되어 있어 연도 확정은 보류한다. 기록 날짜 AB-LOG!X4는 `2026. 5.31`, 항차 식별자 J4는 `266-2026-04`이다. 원본 XLSX와 개인 대화 이미지는 저장소에 공개하지 않는다.

| 항목 | 값 | 근거 | 판단 |
|---|---:|---|---|
| 상단 ROB | 670.3 M/T | AB-LOG!S26 | 기준 시각 미확인 |
| 소비량 | 195.2 M/T | AB-LOG!S42 | 독립 측정 또는 차감 산출 여부 미확인 |
| 하단 ROB | 475.1 M/T | AB-LOG!S41 | 기준 시각 미확인 |
| 기관별 소비량 합 | 195.2 M/T | AA, AB, AC, AD, AF, AH열 10~18행 | 기록 내부 일치 |
| 일별 선택 숫자 합 | 228.9 | B FOAM!T8:V68 | 단위·기간·범위 미확인, 비교 보류 |
| 급유량 | 미확인 | AB-LOG!S27:S40 공란 | 숫자 0으로 바꾸지 않음 |

급유가 없었다는 기관 답변의 전달 내용을 조건으로 670.3 − 195.2 − 475.1 = 0.0이다. 원본 숫자의 저장 오차를 위해 10^-6의 산술 허용오차를 사용하며 운항 안전기준이 아니다. 집계된 셀 수는 완전성의 증거가 아니다. 일별표 숫자와 요약표의 차이를 손실이나 오류로 단정하지 않는다. Sheet1의 미표기 계산과 일별표 아래 메모는 집계에서 제외한다.

## 구현

`python scripts/review_ab_log.py /path/to/workbook.xlsx --output /path/to/new-review.json`

- 이 한바다호 양식에 한정한 읽기 전용 XLSX 검토기. 원본 수정·학습·자동 항차 CSV 변환 없음.
- 양식의 표제·단위·기관별 열을 확인한다. 필수량 누락, 음수, 비유한값, 수식 캐시는 거부한다.
- ZIP 크기·압축해제 총량·중복 항목·XML 엔티티를 제한한다. 출력 파일 덮어쓰기를 거부한다.
- 보고서는 원본 SHA-256, 셀 주소, 원시 정밀도 합계, 조건부 수지 상태, 일별 대조 보류를 출력한다.
- `reported_year=2025`와 무급유 전달 출처는 이번 수령 건의 맥락이다. 다른 선박·다른 자료의 일반 분석기로 사용하지 않는다.
- `status=review_pending`은 산술 일치 후에도 유지한다. 실제 구매량·가격·정책 안전성을 검증하지 않는다.
- 웹은 검토 결과 JSON을 읽어 한·영 표와 다운로드를 제공한다. 웹에서 XLSX를 직접 파싱하는 기능은 아니다. 기존 로컬 항차 CSV 검토 기능은 유지한다.

집계 결과: `results/real_voyage/hanbada_review.json` 및 동일한 웹 공개 집계 JSON. 원본은 포함하지 않는다.

## 해기원 검토용 논문

`docs/submission/ack_paper_v5_5.md`는 합성 정책 비교와 실선 기록의 제한적 내부 검산을 구분한다. 제공 경위·비공개 자료 인용·근거 셀·연도 불일치·일별표 대조 보류를 서술한다. 기존 실험 수치와 모델은 변경하지 않았다. 저자 영문명·이메일은 최종 확인이 필요하며 해기원 전달은 아직 실행하지 않았다.

다음 확인사항은 대상 연도, ROB 기준 시각, 소비량 산출 방법, 두 시트의 기간·단위·집계 범위다. 확인 전에는 실측 정확성·실제 정책 성능·비용절감을 주장하지 않는다.
