# 한바다호 AB-LOG 검토 기능과 논문 v5.5 정정본

제공기관 최종 회신을 반영한 현재 설명이다. [회신 근거와 확정·추정 구분](hanbada_provider_clarification.md)을 참조한다.

## 확인 범위

- 대상: 2026년 5월 한바다호. AB-LOG!X4는 월말 제출일이다.
- AB-LOG!S26=670.3, S41=475.1, S42=195.2 M/T. 소비량은 ROB 차감값이므로 산술 일치는 독립 측정 검증이 아니다.
- 기관별 소비량 선택 범위 합계 약 195.2 M/T는 기록 내부 합산이다.
- B FOAM!T8:V68의 기재값 합계 약 228.9 kL. 초기 M/T 안내는 제공기관 최종 답변으로 정정됐다.
- 밀도·부피 기준 조건·집계 시간 정합성이 미확인이라 kL→M/T 환산 및 직접 대조를 보류한다.
- Sheet1은 실수로 포함된 무관한 시트이므로 제외한다. ×0.95는 사용하지 않는다.
- 초기 ROB 5월 6일 15:54경, 종료 약 13시경 및 정오 접안 설명은 담당자 추정이다.
- 빈 급유 칸은 null로 유지한다. 원본 XLSX는 비공개이며 제공기관은 이 조건으로 인용·공개를 허용했다.

## 구현

`python scripts/review_ab_log.py /path/to/workbook.xlsx --output /path/to/new-review.json`

양식 전용 읽기 검토기는 ZIP·XML 크기, 중복 항목, 표제·단위·기관 열을 검사하고 누락·음수·비유한값·수식 캐시를 거부한다. 원본과 기존 출력 파일을 덮어쓰지 않는다. 출력 schema v2는 원본 SHA-256에 결합된 제공기관 확인정보를 별도 필드로 표시한다. 다른 원본에는 확인정보를 적용하지 않는다. 원시 정밀도 합계와 셀 근거를 보존하며 10^-6은 숫자 저장 오차 허용치이지 운항 안전 기준이 아니다.

집계 결과는 `results/real_voyage/hanbada_review.json`과 웹 공개 JSON에 동일하게 기록한다. 웹에서 XLSX를 업로드·변환하는 기능은 아니며 기존 항차 CSV 검토를 유지한다. 질량 환산·학습·실선 비용절감 검증은 수행하지 않는다.

## 논문·검증

논문 v5.5 정정본은 연도·단위·ROB 차감 산출·Sheet1 제외를 반영했다. 모델과 합성 실험 결과는 변경하지 않았다. 저자 정보·최종 제출 양식 확인은 별도이며 해기원 회신을 논문 승인으로 해석하지 않는다. 원본 재실행, 단위 혼용·추정 시각·다른 원본 적용 방지 검사 및 기존 웹 근거 검사를 수행한다.
