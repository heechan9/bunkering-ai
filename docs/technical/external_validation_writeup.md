# 외부자료 검증 및 추가 기준선 연구 서술 초안

기존 제출 논문을 변경한 파일이 아니라 후속 연구 설명용 초안이다. 공식 평가와 별도 실험임을 유지한다.

## 방법
배포된 Double DQN 체크포인트를 고정한 상태에서 외부 소비량 자료와 대표 항로·가격 시나리오를 이용해 추가 평가를 수행하였다. FuelCast는 시간순으로 분리한 학습 구간 평균을 기준으로 소비량을 정규화했으며, ONS 통항량은 항로 상황의 맥락 자료로 사용하였다. ONS 통항량을 개별 선박의 지연이나 연료 소비로 직접 환산하지 않았다. 급유 전 소비 부족이 급유로 가려지는 문제를 방지하기 위해 별도 연구 환경에서는 해당 시점에 실패 처리하였다.

과거 소비량에 기반한 안전재고 전략과 최소 예비연료 기준을 추가한 전략을 구현하였다. 전자는 학습 구간의 소비량 사전값과 최근 완료된 구간의 소비를 사용하며, 후자는 합성 최대 소비 가정에 근거한 예비연료 하한을 추가한다. 이러한 입력은 기존 DQN의 관측과 동일하지 않으므로 알고리즘 자체의 인과적 우열 비교로 해석하지 않는다.

## 결과
FuelCast를 반영한 추가 학습은 3개 난수 시드에서 각각 1,500 에피소드로 수행하였다. 검증 구간으로 선택한 후보들은 해당 평가에서 기존 DQN과 같은 성공률을 보였으나 잔여 연료 가치를 보정한 비용 개선은 확인되지 않아 모델 교체를 보류하였다.

후속 최소 예비연료 전략 비교는 6,720회 수행하였다. 기존 DQN과 보완 전략은 시험한 FuelCast 부분 구간 및 합성 소비 급변 조건에서 모두 성공했으나, 보완 전략의 보정 비용지수는 DQN보다 FuelCast에서 0.215~0.521%, 급변 조건에서 0.015~0.094% 높았다. 따라서 기존 DQN을 유지하고 보완 전략은 연구용 비교 기준선으로 활용한다.

## 한계
평가는 정규화된 합성 탱크와 항로 길이를 사용하며 실측 항해시간·탱크 용량을 교정하지 않았다. 같은 선박 자료의 다른 시간 구간은 독립 외부 선박 검증이 아니다. 비용지수는 실제 통화 지출이나 확인된 절감액이 아니다. Strathclyde 자료의 유효동력 그림을 소비량으로 연결하는 과정과 최소 예비연료 기준은 별도의 가정을 포함한다. 정책 교체나 실선 효과를 주장하려면 신규 선박·정확한 운항 및 거래자료를 통한 추가 검증이 필요하다.
