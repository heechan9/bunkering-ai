## 논문 서론에 넣을 문구

해상 수송로의 불확실성은 선박의 연료 확보와 운항 계획을 함께 검토할 필요성을
높인다. 본 연구는 이러한 문제의식을 바탕으로 합성 시장·항해 조건에서 규칙 기반
정책과 Double DQN의 급유 의사결정을 비교한다. 도착 여부뿐 아니라 합성 구매비용,
급유횟수 및 잔량을 함께 검토하여 보상과 운영지표 사이의 상충관계를 분석한다.
이는 실제 호르무즈 위기 대응 효과를 검증한 결과가 아니라, 후속 현장 검증을
위한 재현 가능한 정책 비교 실험이다.

잔량 분석을 결과 기여로 서술하는 것은 학습 체크포인트 진단 완료 이후로 한정한다.
미완료 시 서론에서 잔량은 후속 분석 과제로 표현한다.

## 발표 도입 예시

“해상 수송로가 불안정해질 때, 해운사는 연료를 언제 확보해야 할까요?
병커시유는 여러 급유 정책을 같은 가상 항해 조건에서 비교하고,
도착률과 비용지표가 서로 다른 결론을 줄 수 있음을 보여주는 연구입니다.
실제 위기 대응 시스템은 아니지만, 현장 자료를 연결해 검증할 실험 기반입니다.”

## 시의성과 검증 수준

| 항목 | 위치와 표현 |
|---|---|
| 호르무즈 및 해상교통 안전 논의 | 연구 동기·외부 배경 |
| 한프 협력 및 영불 항행 안전 구상 | 외교·정책 맥락. 프로젝트와 기관 협력 관계를 의미하지 않음 |
| Suez/Cape 대표 조건 | 합성 horizon 민감도. 호르무즈의 대체 항로 모델이 아님 |
| Hormuz observation-only | 환경 변경 없는 관찰 맥락. 독립 충격 실험으로 세지 않음 |
| 소비량 스트레스 | 가정한 정규화 소비량 변화. 실제 봉쇄·대기·전쟁 데이터 검증이 아님 |
| 항만 이용 불가·공급 제약 | 후속 설계 후보이며 이번 작업에서 구현하지 않음 |
| 11월 관심도·수상 가능성 | 예상일 뿐 확정 사실·성과지표로 사용하지 않음 |
