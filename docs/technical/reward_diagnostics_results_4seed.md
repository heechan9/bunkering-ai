# 병커시유 원본 진단 기록 독립 대조

판정: **연료수지·SCI·보상·집계 재현 통과. 안전선 경계의 부동소수점 판정 문제 확인.**

사용자가 제공한 16개 CSV/JSON 파일을 직접 읽고 재계산했다. 제공된 요약 스크립트를 실행해 그 결과만 반복 확인한 것이 아니라, 별도 검증 코드로 원본 step 기록부터 재구성했다. 기존 환경 코드, 체크포인트, 공식 결과는 변경하지 않았다.

## 1. 범위와 출처

- 학습 seed 표기: 42 / 1042 / 2042 / 3042. 각 checkpoint manifest에 서로 다른 SHA-256이 기록돼 있다.
- 원본 12개 파일의 SHA-256이 통합 manifest의 값과 모두 일치한다. 업로드 과정에서 바뀐 파일명은 해시로 연결했다.
- checkpoint 바이너리 자체는 첨부되지 않았으므로 그 바이너리 해시와 학습 이력은 이번 감사에서 재검증하지 않았다.
- 4묶음 × 400개 = 1,600개 항차 기록, 40,120개 step 기록을 대조했다.
- 규칙 정책의 반복 3묶음은 원본 기록까지 동일하다. 중복을 제거하면 규칙 300개 + DQN 400개 = 700개 정책/체크포인트/평가 case 조합이다. 독립 시장 경로 700개라는 뜻은 아니다. 동일한 100개 평가 seed 42~141을 공유한다.
- 환경: max_steps=30, fuel_consumption_per_step=0.05, min_safe_fuel=0.15. 소비량 -10% 또는 horizon stress 결과는 이번 첨부에 없다.
- 기준 환경 소스: `97233c1c442a687aaed4a34e2cadca0d98aa2fb9`.
- 진단 도구 기준: PR #44 HEAD `bdf9340bec6d4af7a0c2376b75255ddc4a16c2e2`.

## 2. 독립 대조 결과

다음 정의로 실제 급유량과 상한 손실을 재구성했다.

```
소비량 = min(기초잔량, 0.05)
소비후잔량 = max(기초잔량 - 0.05, 0)
요청급유량 = 급유 행동이면 0.9, 아니면 0
실제급유량 = min(요청급유량, max(0.95 - 소비후잔량, 0))
상한손실 = max(소비후잔량 + 실제급유량 - 0.95, 0)
기말잔량 = 소비후잔량 + 실제급유량 - 상한손실
```

이는 손실항을 단순 잔차로 정의한 뒤 같은 식을 다시 확인하는 순환 검증을 피하기 위한 것이다.

| 확인 항목 | 결과 |
|---|---|
| 원본 12개 파일의 manifest 해시 대조 | 모두 일치 |
| 중복/누락 case, step 연속성, 초기/최종잔량 | 불일치 없음 |
| 동일 seed·step의 가격·이동평균·환율 | 정책 및 체크포인트 사이 일치 |
| step별 소비·실제급유·상한손실 재구성 | 허용오차 내 일치 |
| 최대 step 연료수지 절대오차 | 1.1102230246251565e-16 |
| 최대 항차 연료수지 절대오차 | 1.5543122344752192e-15 |
| SCI = 실제급유량 × 의사결정 시점 가격 × 환율 | 최대 절대차 2.3283064365386963e-10 |
| 보상 4성분과 원래 수식 재구성 | 최대 reward 절대차 3.191891195797325e-16 |
| policy_summary / checkpoint_summary / case_trace | 원본 재집계와 일치 |

원본 수치에 NaN/Inf가 없고, 현재 기본조건의 상한손실은 0이다. 이 결과는 다른 소비량 조건에서의 손실 유무를 의미하지 않는다.

## 3. 확인된 문제: Safe Stock의 안전선 위반 100%는 수치 경계 효과

Safe Stock의 모든 100개 항차에서 step=16(17번째 전이)의 잔량이 CSV상 `0.1499999999999997`로 기록돼 있다. 안전선 `0.15`와 약 3e-16 차이다. 원래 환경은 허용오차 없는 `< 0.15`로 판정하므로, 각 항차에 위반 1회와 안전 벌점 -0.5를 부여한다.

십진수의 정확한 연산으로는 초기 1.0에서 0.05를 17회 소비한 결과가 0.15이다. 실제 기록의 행동 순서를 고정한 Decimal 연료 전이 재생에서도 Safe Stock의 전이 후 안전선 미달은 0회였다. 전체 기록에 대한 수치 허용오차 1e-12, 1e-10, 1e-8, 1e-6의 후처리 판정 역시 같은 결론이다.

| 정책 | 원래 판정: 위반 항차/평가 항차 | 잔량 < 0.15 - 1e-12로 재분류 |
|---|---:|---:|
| Fixed Fueling | 100/100 | 100/100 |
| Price Reactive | 99/100 | 98/100 |
| Safe Stock | 100/100 | 0/100 |
| Double DQN | 0/400 | 0/400 |

규칙 정책의 반복 기록은 이 표에서 한 번만 세었다. 허용오차 재분류는 **기존 기록의 민감도 분석**이며 공식 결과 교체나 새 환경에서의 정책 재평가가 아니다. Decimal 재생도 행동을 다시 선택하지 않는다.

따라서 “DQN이 실질적인 안전선 위반을 100%에서 0%로 줄였다”는 해석은 이번 기본조건에서는 지지되지 않는다. DQN이 더 높은 잔량 여유를 유지했다는 관측은 유지된다. 실선 안전성이나 step 내부의 연속시간 위험까지 검증한 것은 아니다.

Safe Stock의 원래 reward 평균 -0.4927979에는 이 경계 판정에 따른 -0.5가 포함돼 있다. 동일 기록에서 해당 벌점만 제외하면 약 +0.0072021이지만, 이는 계산상 영향 설명일 뿐 수정된 환경에서 학습·평가한 공식 보상이 아니다. DQN 학습에 같은 보상 경계가 어떤 영향을 주었는지는 확인하지 않았다.

## 4. 구매·소비·잔량 연결

| 평균 항목 | Safe Stock | DQN 4개 체크포인트 평균 |
|---|---:|---:|
| 초기잔량 | 1.00000 | 1.00000 |
| 실제 급유량 | 0.85000 | 1.31325 |
| 소비량 | 1.50000 | 1.50000 |
| 상한손실 | 0 | 0 |
| 최종잔량 | 0.35000 | 0.81325 |
| 항차 SCI | 545392.723905 | 839763.4098485 |
| 급유횟수 | 1.00 | 4.90 |
| 도착률 | 100% | 100% |

```
Safe Stock: 1 + 0.85 - 1.5 = 0.35
DQN 평균:  1 + 1.31325 - 1.5 = 0.81325
```

DQN의 추가 구매량 0.46325는 같은 소비량 조건에서 추가 최종잔량 0.46325와 일치한다. SCI는 Safe Stock보다 53.9741% 높다. DQN의 원본 전이 후 최저잔량은 약 0.30, Safe Stock은 약 0.15이다. 이것으로 최적 구매 시점이나 재고가치 차감 후 경제성의 우위를 주장할 수 없다. `step_sci_mean`은 이 요약표에서 step당 SCI가 아니라 step SCI를 항차별 합산한 후 낸 평균이다.

## 5. 소량 다회 급유: 관측 사실과 미검증 인과 분리

- DQN 400항차에서 실제 급유 1,960회, 항차당 평균 4.90회.
- 급유량 최솟값 0.05, 중앙값 약 0.30, 최댓값 약 0.70.
- 한 step의 소비량 0.05 이하인 급유는 529회(26.99%). 이 데이터에서는 부동소수점 허용오차 내 0.05 급유다.
- 이 급유들이 DQN 가격우위 보상 합계의 57.86%를 차지한다.
- 따라서 작은 보충 급유가 반복되고 그때 가격우위 보상이 발생한 사실은 관측됐다.
- 그러나 “구매량 비례가 아닌 보상이 이 행동을 원인적으로 만들었다”는 결론은 아직 불가하다. 보상 변경과 재학습 등을 통한 분리 실험이 필요하다.

## 6. 다음 보완과 결과 보존

1. 현재 공식 결과와 학습된 체크포인트를 그대로 보존한다.
2. 논문·개발현황에서 Safe Stock의 100% 위반을 실질적인 안전성 열세로 해석한 문구를 정정한다.
3. 별도 변경안에서 안전선 경계 비교 원칙을 정하고, 환경 보상과 진단 판정에 일관되게 적용한다. 경계값 및 경계에서 충분히 떨어진 실제 미달을 구분하는 회귀 검증이 필요하다.
4. 먼저 기존 행동 기록을 이용한 민감도 분석을 제시하고, 환경 수정 후 기존 checkpoint 평가와 재학습은 서로 분리한다. 자동으로 5,000회 재학습을 요구하지 않는다.
5. 수정된 보상으로 학습한 DQN의 행동까지 주장하려면 별도 재학습 근거가 필요하다. 이번 감사는 그 작업을 수행하지 않았다.

최종적으로, 현재 합성 항차에서 구매·소비·잔량은 수치적으로 일관되게 연결돼 있다. 외부 실제 항차 자료와의 일치나 실제 비용절감은 이번 파일로 검증할 수 없다.

## FuelCast와 실항차 자료의 상태

이번 결과는 사용자 PC의 기존 합성환경 진단 자료만 사용했다. FuelCast 데이터는
이번 환경·학습·평가·논문 실험에 포함하지 않았다. 독일 KROHNE Digital이 공개한
FuelCast는 V2의 연료소비 모델 후보로 남긴다. 공개 스키마에는 구매가격·ROB·실급유량을
같은 항차로 연결할 필드가 없으므로 이번 구매 의사결정 검증을 대체하지 않는다.
별도 활용 시 kg/s와 시뮬레이션 단위의 연결, 선종 차이, 시간 분리 검증과
CC BY-NC-ND 4.0 조건을 먼저 검토한다.
[공개 데이터](https://huggingface.co/datasets/krohnedigital/FuelCast)

실제 항차의 소비·급유·잔량·가격 연결 자료 확보도 별도 과제다. 이번 보완으로
현장 성능이나 실제 비용절감을 검증했다고 표현하지 않는다.
