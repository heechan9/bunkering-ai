# Ocean Lab: 의사결정과 검증 근거를 함께 보여주기

2026-09-19. 사용자가 제공한 영업관리·HRD 특강과 AX 포트폴리오 특강을 웹 결과 해석 및 팀 검토 절차에 적용했다. 강의는 프로젝트 구성 참고이며 해운 실무 또는 연구 성능의 검증 근거가 아니다.

## 웹에 반영한 내용

- 전략 비교표에 기존 `bunkering_count_mean` 기반 평균 급유횟수를 표시한다. 실험 데이터를 추가 생성하거나 변경하지 않는다.
- 구매 담당자의 관점에서 SCI·구매량·최종재고를 함께 해석하고, 운항 담당자의 관점에서 도착·안전여유·급유빈도를 구분한다.
- Safe Stock 수치 경계 정정 사례를 기존 근거 문서에 연결한다. 허용오차 후처리와 재학습을 구분한다.
- 현장 검토 및 항차 자료 반영이 대기 중임을 표시한다. 사람이 정한 요구사항과 AI 지원 역할은 `CONTRIBUTIONS.md`에 연결한다.
- 한국어·영어 설명을 함께 제공하고 상세 내용은 펼침 영역에 배치한다.

## 팀원 회신 반영 절차

민재의 안전잔량·누락 제약·결과 해석 검토와 승현의 울산항 자료 의미·항차 연결 검토는 기존 요청 범위를 유지한다. 각 회신은 아래 형식으로 통합한다. 승현의 원자료 검토는 수령·대조·정정 반영을 완료했다([근거](../data/upa_review_20260919.md)). 민재 회신은 수령·내용 검토 및 GitHub 기록 반영 완료다. 원고·배포 웹 반영, 제공기관 용어 확인과 해기원 실측 자료 수령은 별도 남은 작업이다.

| 검토 항목 | 실제 필드 또는 현재 가정 | 근거·페이지 | 사실/경험/의견/미확인 | 채택/부분 채택/보류 | 수정 위치 | 추가 필요 자료 |
|---|---|---|---|---|---|---|
| 승현 원자료 검토 | 공개 CSV 8개 필드 | [대조 기록](../data/upa_review_20260919.md) | 확인/미확인 구분 | 정정 후 반영 | 웹·논문 v4.0 이후 | 공급량 의미·단위·연결 항차 자료 |
| 민재 팀 내 해양 분야 검토 | 안전잔량·누락 제약·해석 | [검토 기록](minjae_domain_review_20260920.md) | 의견과 미확인 수치 구분 | 정성적 한계 채택, 기준 변경 보류 | GitHub 기록 완료; 원고·배포 웹 반영 대기 | 실측 항차 자료·기준 근거 |

해기원 자료를 받으면 동일 항차 식별, 단위·연료 종류·시각 정합성을 먼저 확인한다. 출발잔량+실급유량−소비량과 도착잔량을 대조하고 불일치 원인을 미확인 상태에서 단정하지 않는다. 실측 사례는 합성 결과와 별도로 제시한다. 비용절감이나 현장 안전성 입증으로 확대 해석하지 않는다.

## 적용 범위와 검증

수치 원본은 `web/ocean-lab/public/data/replay.json`이며 DQN 급유횟수는 네 체크포인트의 평균이다. 이번 수정은 웹 설명과 기존 지표 노출, 검토 절차 문서화다. 새 학습·현장 실험·논문 원본 수정은 포함하지 않는다. ACK 9월 30일 접수를 위해 새 기능보다 근거 정리와 회신 반영을 우선한다.

Requirements/Planning: 최희찬의 강의 적용 요청. Implementation/AI-assisted editing: Codex. 실제 도메인 검토는 팀원·멘토 회신과 구분한다.
