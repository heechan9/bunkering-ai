# 한바다호 집계 비교 및 가정 민감도 실험

## 목적과 계약

원본 해시가 확인된 2026년 5월 AB-LOG를 읽고 집계 숫자만 공개한다. 일별표는 kL, 요약표는 M/T다. 실측 밀도·부피 기준 조건·정확한 시간 정합성이 없는 상태에서 원시 두 수치의 직접 차감은 수행하지 않는다. 다음 작업을 분리한다.

1. 같은 단위 안의 직접 비교: 일별표 선택 날짜 범위별 kL, 요약 기관별 M/T 합계와 ROB 차감값.
2. 가정 실험: 선택 범위 3개 × 분석자가 정한 공통 밀도 5개(0.800, 0.825, 0.850, 0.875, 0.900 t/kL) = 15개 결정론적 산술 시나리오. 이 격자는 실측값·연료 규격 범위·신뢰구간이 아니며 온도 보정을 하지 않는다. Sheet1의 0.95는 사용하지 않는다.
3. 역산 진단: 195.2/V를 계산해 총량을 맞추는 비율을 제시한다. 이를 실제 밀도로 추정하거나 관측 정확성 검증에 사용하지 않는다.

날짜 범위는 B FOAM의 날짜 표기 행 선택이며 실제 항차 시각으로 잘라낸 기간이 아니다. 출항일 일부 시간·마지막 날 경계 시간의 배분을 임의로 하지 않는다. 날짜 수식 캐시는 일정 라벨로만 사용하며 소비량 셀 수식은 거부한다. 빈 칸은 합산에서 제외하고 관측된 0으로 바꾸지 않는다.

## 같은 단위의 비교

| 선택 날짜 행 | M/E kL | G/E kL | Boiler kL | 합계 kL | 195.2/V 역산 비율 t/kL |
|---|---:|---:|---:|---:|---:|
| 01~31일 | 123.4 | 79.4 | 26.1 | 228.9 | 0.852774 |
| 06~31일 | 123.4 | 79.4 | 23.4 | 226.2 | 0.862953 |
| 06~30일 | 107.3 | 76.3 | 22.9 | 206.5 | 0.945278 |

1~5일 선택 행의 기재 부피 합은 2.7 kL, 31일 선택 행은 19.7 kL이다. 이를 제외하는 것은 시간 범위 민감도 계산이지 그 기록이 잘못됐다는 판정이 아니다. 요약표 기관별 기재 합계는 M/E 93.1, G/E 76.6, Boiler 25.5 M/T로 합계 약 195.2 M/T다. 670.3−475.1=195.2는 제공기관이 설명한 소비량 산출 관계이며 독립 계측 검증이 아니다.

## 민감도 결과와 해석

가령 공통 밀도를 임의로 0.850 t/kL로 놓으면 1~31일 합계는 194.565 t, 요약표 대비 −0.635 t(약 −0.325%)이다. 같은 가정에서 6~31일은 192.270 t, 6~30일은 175.525 t다. 이 예시는 수치가 가까워져도 집계 기간과 밀도가 확인됐다는 뜻이 아님을 보여준다. 0.850은 결과를 검증하는 실측 근거가 아니다.

전체 1~31일을 대상으로 기관별 요약 질량/일별 부피 비율은 M/E 약 0.754457, G/E 0.964736, Boiler 0.977011 t/kL로 서로 다르다. 따라서 총합을 맞추는 하나의 계수만으로 세 기관의 값이 동시에 일치하지는 않는다. 각 비율은 서로 다른 집계 범위·측정 조건이 섞일 수 있는 단순 수치비이며 실제 기관별 연료 밀도나 오류의 원인으로 단정하지 않는다.

15개 시나리오 전체는 `results/real_voyage/hanbada_comparison.json`에 있다. 이는 동일 원본으로 계산한 결정론적 민감도 분석이며 15개 독립 실험 표본·학습 실험·통계적 유의성 검증이 아니다. DQN 재학습·실선 정책 비교·비용절감 실험은 수행하지 않는다.

## 재현

원본을 가진 검토자: `python -m scripts.compare_ab_log --workbook /private/AB-LOG.xlsx`

원본 없이 집계 계산 재현: `python -m scripts.compare_ab_log --check`

검사: `python -m unittest discover -s tests -p 'test_ab_log*.py' -v`

공개 입력은 원본 해시에 연결된 기관별·선택 기간별 집계뿐이다. 원본·메일 전문은 저장소에 포함하지 않는다. `--check`는 공개 집계와 결과의 산술 일치를 확인하며 원본 정합성이나 외부 측정 정확성을 인증하지 않는다.
