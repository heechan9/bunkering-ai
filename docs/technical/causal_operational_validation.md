# 현장 인과·운영 검증 계획

## 목적과 주장 경계

현재 공식 비교는 합성 항해 환경에서 동일한 조건으로 정책을 비교한 **오프라인 시뮬레이션 결과**다. 이는 구현과 정책 간 성능 차이를 검증하지만, 실제 선박에 적용했을 때 연료비·결항·안전사건이 감소한다는 인과효과를 입증하지 않는다. 실제 원화 비용, 탄소배출 또는 사고 감소는 별도의 현장 검증 전에는 목표 또는 가설로만 표현한다.

## 검증 질문과 지표

| 질문 | 주 지표 | 함께 볼 안전·운영 지표 |
| --- | --- | --- |
| 정책 추천이 실제 총비용을 낮추는가 | 항차별 연료·환율·서비스 비용 | 재고고갈, 안전재고 위반, 지연, 급유횟수 |
| 추천이 운항을 방해하지 않는가 | 정시 도착률 | 선장·운항자 개입률, 경보 수, 추천 거부 사유 |
| 효과가 특정 조건에만 국한되는가 | 항로·선종·가격변동 구간별 효과 | 기상, 적재, 항만 혼잡, 계약조건별 오류 |

총비용 개선만 단독으로 최적화하지 않는다. 비용이 낮아도 안전재고 위반이나 운항자 부담이 커지면 배포 기준을 통과할 수 없다.

## 단계적 평가

1. **재생·그림자 평가**: 과거 항차 로그에 정책을 실행하되 추천은 실제 결정에 사용하지 않는다. 관측된 실제 결정과의 차이, 결측 및 지원 범위를 점검한다. 과거에 선택되지 않은 행동의 결과는 관측되지 않으므로 이것만으로 절감 효과를 단정하지 않는다.
2. **제한적 전향 평가**: 가능한 경우 비교 가능한 선박·항차 묶음 안에서 추천 노출을 무작위 배정한다. 선박 간 간섭과 항차 연속성을 고려해 선박 또는 시간 블록 단위 배정을 우선 검토한다.
3. **단계적 도입**: 무작위 배정이 어렵다면 도입 전후 변화와 아직 도입하지 않은 유사 집단의 변화를 비교한다. 도입 전 평행추세를 시각화·검정하고, 유가·환율·항만·기상·화물·용선정책의 동시 변화를 기록한다.
4. **임계값 기반 평가**: 고정된 재고·위험 임계값이 실제로 추천 노출을 결정하고 임계값 주변 조작이 어렵다는 조건에서만 불연속 설계를 검토한다. 사후에 임계값을 골라 효과를 만들지 않는다.

## 사전등록과 분석 단위

- 처치: 어떤 정책 버전의 추천을 누구에게 언제 노출했는지
- 비교군: 같은 기간의 무노출 또는 기존 규칙 기반 의사결정
- 분석 단위: 선박·항차·의사결정 시점을 혼용하지 않고 사전 고정
- 일차 지표, 제외 기준, 관측 기간, 최소 표본과 중단 기준을 분석 전에 고정
- 선박별 반복 관측과 항로 군집을 반영한 불확실성 구간 보고
- 전체 평균과 함께 선종·항로·가격변동·기상 조건별 결과 및 표본 수 보고

## 선택 편향과 인간 감독

추천을 수락한 항차만 분석하면 좋은 조건에서 수락된 결과를 정책 효과로 오인할 수 있다. 모든 추천, 미노출 결정, 수락·거부, 수정값과 사유를 기록하고 원래 배정 기준으로 분석한다. 선장과 운항 담당자의 최종 권한, 즉시 우회, 안전 중단 조건을 유지하며 자동 실행은 별도 안전성 검증 전에는 허용하지 않는다.

## 근거 및 저작권 경계

이 문서는 인과추론의 일반 원칙을 프로젝트 상황에 맞게 독자적으로 정리한 것이다. 외부 교육자료의 녹취·슬라이드·도표·고유 사례를 복제하지 않으며, 외부 공개 시에는 실제 사용한 원자료·논문·공식 통계의 출처와 라이선스를 별도로 확인한다.
