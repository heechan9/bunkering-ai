# 멘토 전달 후 표시와 조판 보완 — 2026-09-22

## 범위

사용자가 멘토에게 논문을 이미 전달했음을 확인했다. 기존 v7.0 MD·DOCX·PDF는 보존하고, 조판 수정본 `ack_paper_v7_0_layout.docx`·`.pdf`를 추가했다. 논의의 울산항 자료와 Ocean Lab 두 문단의 줄간격·들여쓰기만 인접 본문과 통일했다. 모든 문단과 표의 텍스트가 원본과 동일함을 검사했고 3쪽 전체 렌더링을 검토했다. 내용 개정이 아니므로 v7.5로 올리지 않는다.

## 웹

- 논문 링크: v6.0 → v7.0, 별도 조판 수정본 PDF 링크 추가.
- 탭·경계 사례·근거 펼침·하단 근거 링크의 접근성 이름을 현재 언어로 명시.
- 알림은 번역된 문장을 상태에 고정하지 않고 현재 언어로 렌더링.
- Web Crypto를 사용할 수 없는 HTTP 환경의 CSV 오류를 HTTPS 사용 안내로 교체. SHA-256 없이 비교를 진행하거나 임의 해시를 생성하지 않는다.
- 연구 수치, 재생 기록, 지도·3D 구현, 의존성은 변경하지 않음.
- 웹 README와 추적 소스 137개 해시 목록을 Sites 저장 버전 22의 소스에 맞춤. 저장과 실제 배포 완료는 별도 확인 대상이다.

## 검증

- TypeScript 타입 검사 통과.
- 번역 317항목·수치 자리표시자·7개 도착 표식·기존 재생 값 검사 통과.
- CSV 0/빈칸·단위·날짜·중복·수지·수식 주입 방어·CP949·열별 오류 요약 검사 통과.
- 공유 링크 직렬화/복원 왕복과 잘못된 값의 기본값 처리 검사 통과.
- AB-LOG 관련 단위 검사 15개 통과.
- 정본 대조: 요약 수치 70개, 정책/사례 조합 700개, 전이 19,030개 통과. 새 모델 실행이 아니다.
- 프로덕션 빌드 성공.
- 브라우저: 수정된 영어 탭의 표시와 aria-label 일치 확인; CSV 빈 양식 다운로드 파일의 헤더 확인.
- 브라우저 CSV 입력은 HTTP 미리보기의 Web Crypto 제한으로 전체 진행 불가. 자동 CSV 검사는 통과했으나 실제 HTTPS 업로드→결과 다운로드 E2E 완료로 기록하지 않는다.
- 브라우저의 반복 입력/스크롤 응답 지연 때문에 공유 링크 재접속·실제 모바일·모바일 GPU의 전체 검증은 미완료다. 미리보기 제한을 공개 사이트의 결함으로 단정하지 않는다.
