## 브라우저 검증 한계

로컬 개발 서버는 응답 200까지 확인했다. 그러나 클라우드 실행 환경의 Chromium은
`process_singleton_posix.cc: socket() failed: Operation not permitted`로 시작하지 못했다.
허용된 권한 확장 경로 재시도도 같은 제한이었다. 따라서 다음은 **미실행**이다:

- 실제 브라우저 버튼·입력·다운로드 클릭, 탭·단계 변경 중 상태 복원
- 데스크톱/360px/390px 시각 QA·가로 넘침 검사, 스크린샷
- 실제 모바일, iOS Safari, WebGL/GPU 검사

계산 함수의 반복사용·새 입력·내보내기 검사를 브라우저 조작 검증으로 대신 표기하지 않는다.
브라우저를 사용할 수 있는 환경에서 확인할 체크리스트:

1. 운항 체험 시작 → 10단계 → 정상(4/4), 마감 충돌(1/4), 누락(구매 후보 보류).
2. 빈 출항 준비/이송을 채워 정상 복구, 음수 입력은 오류, 정상 예시 버튼으로 복구.
3. 입력 변경 후 단계·언어 변경 → 최신 잔량/결정/SCI 재계산·시간 입력 유지 확인.
4. JSON 두 번 저장 → 현재 입력·정책/체크포인트/사례·단계·반올림 전 결과 대조.
5. 마지막 단계/종료 이동 및 재시작 → 1단계/종료 안내/초기화 동작 확인.
6. 1440px, 390px, 360px에서 표 내부 스크롤·입력 라벨·버튼·본문 확인.

## 해석

고정 현재가로 재고를 보정하면 적격 후보의 보정 SCI는 동률이다. 이 기능은
비용 절감이나 경제적 우위를 보인 실험이 아니다. 시간 결과는 미검증 합성 가정에 따른
산술 검토이며, 제약 통과가 실선 운항 가능성·항차 전체 안전성을 보증하지 않는다.
