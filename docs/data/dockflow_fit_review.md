# Dockflow와 병커시유 데이터 요구의 접점

2026-09-12 공식 웹사이트와 공개 문서 검토. 계정 연결·API 호출·데이터 확보는 수행하지 않았다.

**판단: 향후 항차 지연 맥락을 보완할 후보이며, 현재 필요한 구매·소비·잔량 연결 자료를 제공하는지는 확인되지 않았다.**

Dockflow는 벨기에 Antwerpen에 사무소를 둔 해상 물류 가시성 서비스다. 공개 설명은 AIS·터미널·선사 정보를 결합한 컨테이너 추적에 초점을 맞춘다. 문서에서 ETA 변경·하역 이벤트와 API 연동 경로를 안내한다.

| 우리에게 필요한 항목 | 공개 자료에서 확인한 범위 | 활용 판단 |
|---|---|---|
| 항차·항만 도착 및 지연 | 컨테이너 위치·상태, ETA 변경, 하역 이벤트 | 같은 선박·항차와 식별자를 연결할 수 있다면 V2 지연 시나리오 후보 |
| 실제 급유 구매·인도량·단가 | 해당 원자료 제공 여부 확인 못 함 | 구매명세 확보를 대체하지 못함 |
| 구간별 실측 소비량·ROB | 같은 항차의 원시 기록 제공 여부 확인 못 함 | 구매·소비·잔량 수지 검증에 바로 사용 불가 |
| 탄소배출 | RealCalc와 GLEC 기반 계산 기능을 설명 | 배출 추정값을 선박의 실측 소비·ROB로 간주하지 않음 |
| 연구용 접근 | 무료 30 shipments 데모와 API 문서 안내 | 무료 연구 데이터·API 권한·재배포 허가는 별도 확인 필요 |

연동을 결정하기 전에 샘플 내보내기 자료의 식별자·시간대·예측/실측 구분, 과거 ETA 변경 이력, 연구용 접근 조건을 확인한다. 실제 연료 기록이 제공되는 경우에만 같은 선박·항차·연료 종류·시간 구간으로 구매/소비/ROB를 연결할 수 있는지 추가 검토한다. API가 있다는 사실만으로 ChatGPT 플러그인 설치 가능성이나 무료 원자료 제공이 보장되지는 않는다.

현재 공식 결과와 학습 입력에는 추가하지 않는다. 자료를 얻더라도 새로운 외부 데이터 검증으로 분리한다.
