## 데이터 품질과 해석 한계

평균은 극단값의 영향을 받으므로 시나리오 참고에는 중앙값과 사분위 범위를 우선한다.
중복·0 벙커량·음수 일정기간·음수 신청 리드타임 기록은 원인을 확정할 수 없으므로 임의
삭제하거나 수정하지 않는다.

총톤수 628,121인 기록 2건은 물리적으로 비현실적인 이상치 가능성이 있다. 벙커량은
0.2부터 30,000까지 분포하고 공식 단위가 기재되지 않아 단위 혼재 여부를 확정할 수 없다.
따라서 총톤수·벙커량의 원시 최댓값을 시뮬레이션 파라미터로 직접 사용하지 않는다.

`입항년도`와 예정시작일의 달력연도가 다른 기록이 있으므로 입항년도를 단순 달력연도로
단정하지 않는다. 또한 2024년은 8월까지의 부분연도이므로 연도별 건수 감소를 연간 추세로
해석하지 않는다.

## 현재 구현에 반영한 범위

이 데이터는 실제 벙커링 업무에 `총톤수`, `벙커량`, `작업 예정기간`,
`신청 리드타임` 같은 변수가 존재한다는 점을 확인하는 **도메인 참고자료**로 사용한다.
기초통계는 향후 BunkeringEnv의 선박 규모·급유량·시간 제약 시나리오를 설계하고 실증
범위를 정하는 근거로 활용한다.

현재 Rule-based 공식 평가와 Double DQN 20-episode smoke test는 기존 합성 시계열
환경에서 수행되었다. 이 공공데이터를 DQN 학습 입력, 공식 성능평가 데이터 또는 실시간
API로 사용했다고 주장하지 않는다. 공공데이터 기반 환경 보정·재학습·동일조건 평가는
향후 별도 실험으로 구분한다.
