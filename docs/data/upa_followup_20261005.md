## 시간·비용 모델 보완 기준

추후 기록 수집 시 대기, 준비·점검, 연결·시험, 이송, 종료점검·분리의 시작/종료를 구분한다. 하역과 동시 진행한 구간은 겹친 시간을 두 번 더하지 않는다. 실제 지연시간은 각 작업의 단순 합이 아니라 선박 출항을 늦춘 시간을 별도로 산출한다. 현재 공개 절차에는 정량 소요시간이 없어 임의 시간 상수를 학습에 추가하지 않는다.

급유비용은 연료 구입비와 항만시설 사용료·부대비·감면을 구분한다. PortWise 지원 안내에는 조건부 사용료 감면이 있지만, 최신 요율·적용 자격·실제 청구내역 확인 전 보상함수에 감면을 자동 적용하지 않는다. 시설사용료 감면은 연료소비 감소가 아니다.

## 추가 자료 확보 조건

- 벙커량: 단위(질량/부피), 측정 기준, 신청량/실공급량, 수정·취소 처리 정의.
- 연결: 개인정보를 배제한 일관된 선박 가명 ID, 신청/배정/공급 사건 ID, 항차 ID. 행마다 무작위 ID를 새로 부여하면 시계열 연결 불가.
- 급유: 일시·시간대, 항만, 연료 종류, 공급량·단위, 실제 시작/종료, 계측 또는 공급확인서 여부.
- 재고 검증: 동일 선박의 전후 ROB와 측정 시각, 구간 소비량, 중간 추가 공급·이송·배출 보정. 항만공사가 선내 ROB를 보유한다고 가정하지 않는다.
- 비용 검증: 가격·통화·세금/부대비 포함 범위. 가격이 없으면 수량·시간 검증까지만 수행.
- 이용: 연구 분석·논문 집계 공개·원본 재배포의 허용 범위를 각각 확인.

## 공개 명세 추가 확인 및 원파일 확보 상태 (2026-10-05)

신청현황의 공식 컬럼 정의를 재확인했다. ‘벙커량’의 항목 설명은 ‘벙커량’, 단위는 ‘-’로 표시된다. 수치가 공개되어 있다는 사실과 그 수치가 톤·kL 중 무엇인지, 신청량·실공급량 중 무엇인지를 확인했다는 사실은 다르다. 확인한 CSV 및 공개 명세만으로 후자의 정의를 확정할 수 없다. 다른 공개 문서에도 정의가 전혀 없다고 단정하지 않는다.

배정현황 원파일 다운로드를 시도했으나, 이 작업 환경의 HTTP 요청과 브라우저 모두에서 502 Bad Gateway / Connection refused가 발생했다. 브라우저 재시도도 동일했다. 검색으로 읽힌 목록·컬럼 명세와 원파일 확보를 구분한다. 10,099행은 포털 기재값이며 독립 재검산 결과가 아니다. 로그인 없이 파일 다운로드가 가능하다는 포털 안내가 있으므로 비공개 자료로 판정하지 않는다.

원파일 확보 후 다음 순서로 검산한다.

1. 원본 파일명·확보일·SHA-256·인코딩과 실제 행/열 수를 기록한다.
2. 완전중복, 날짜 결측·파싱 실패, 예정/배정 기간 역전을 점검한다. 배정종료일 공란은 곧바로 0시간으로 치환하지 않는다.
3. 연도+항차 조합의 중복을 확인하되, 유일하게 보이더라도 선박·사건 대응 근거 없이 신청현황과 결합하지 않는다.
4. 예정·배정 일정의 기술통계까지만 산출하며 실공급량·실제 이송시간·연료절감률을 생성하지 않는다.

현재 남은 확보 항목은 배정 CSV 원본과 벙커량 정의의 공식 근거다. 기관 문의 초안은 아래에 준비되어 있으며 발송하지 않았다.

## 기관 문의 초안 — 미발송

안녕하세요. 선박 급유 의사결정 최적화 프로젝트 병커시유 팀장 최희찬입니다. 귀 공사의 벙커링정박지 신청현황(15132700)을 업무 참고자료로 활용하고 있습니다. 공개자료의 정확한 해석과 연구 검증을 위해 아래 사항을 문의드립니다.

1. 공개 컬럼 ‘벙커량’의 단위와 의미가 무엇인지, 신청량인지 실제 공급량인지 확인 부탁드립니다.
2. 신청현황과 배정현황(15121255)을 연결할 수 있는 익명 신청번호 및 일관된 선박 식별자를 제공할 수 있는지 문의드립니다.
3. 과거 친환경 벙커링 인센티브 안내에 제출서류로 기재된 Bunker Delivery Receipt 및 작업일지와 관련하여, 현재 보유 중인 자료에서 업체명·서명 등 민감한 내용을 제외한 급유일시·연료 종류·공급량·단위·작업시간의 연구용 제공이 가능한지 문의드립니다. 보유하신 항목만으로도 검토 가능합니다.
4. 해당 자료의 연구 분석 및 논문 내 익명 집계 결과 공개 가능 범위도 안내 부탁드립니다. 원본 공개는 별도 허락 없이 진행하지 않겠습니다.

선내 잔량·소비 기록은 별도 선박 측 자료와 연결 가능성을 검토할 예정이며, 귀 공사에 해당 기록이 있다고 전제하는 요청은 아닙니다. 담당 부서가 다른 경우 연결을 부탁드립니다. 감사합니다.
