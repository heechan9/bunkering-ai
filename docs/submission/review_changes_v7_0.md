# v7.0 통합 복원

병커시유 ACK2026_Bunkering_v4.5.docx를 직접 바탕으로 작성했다. 평가 조건 표, 소비량 그래프 원본 이미지, 상세 tail 수치, 영문 저자·소속, 논의 및 한계와 별도 결론을 보존했다.

해기원 정정(2026년 5월, 일별 kL, ROB 차감, Sheet1 제외, 추정 시각), 날짜 범위 3개와 밀도 가정 15개 및 비교표를 추가했다. 비판적 검토의 비용·재고 해석, 재학습 미수행 및 고정 사례 민감도 범위를 통합했다. 표 4개·그림 1개, A4 3쪽을 렌더링하고 모든 쪽을 확인했다.

v4.5 원본 DOCX의 CJK 글꼴이 PDF 변환에서 줄 높이를 크게 확장하여 9pt 이하 일반 문단에 고정 11pt 행간을 적용했다. 원고 내용과 결과를 삭제하거나 글꼴 크기를 축소하지 않았다. 원본 PDF와 픽셀 단위로 동일한 조판을 뜻하지 않는다.

멘토 최종 피드백과 저자 확인은 미완료이며 추가 학습 실험을 수행했다고 주장하지 않는다.
