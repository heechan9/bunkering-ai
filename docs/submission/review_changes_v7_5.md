# v7.5 내용 보완과 제목 정합성 검토

v7.0 멘토 전달 이후 사용자의 요청에 따라 별도 내용 개정본을 작성했다. v7.0 및 layout 파일은 보존한다. 멘토 피드백 수령·승인이나 새 실험 수행을 뜻하지 않는다.

## 제목과 기여

- 국문: 합성 항해환경에서 Double DQN 벙커유 구매정책의 민감도 및 연료수지 분석
- 영문: Sensitivity and Fuel Balance Analysis of a Double DQN Bunker Purchasing Policy in a Synthetic Voyage Environment
- ‘강건성’을 ‘민감도’로 구체화하여 고정 시장 사례에서 소비량·horizon을 바꾼 실험 범위를 반영했다.
- 초록·서론·결론을 보상·구매량·잔량의 관계 및 수치 경계 효과를 분석하는 기여에 맞췄다. 비용절감·실선 성능 우위는 주장하지 않는다.
- 실선 절 제목은 ‘실선 기록의 단위 및 집계 범위 점검’으로 바꿔 외부 성능 검증과 구분했다.

## 본문 한계 보완

기존 민재 검토의 채택 범위에 근거하여 항만 공급·연료 규격, 급유·대기시간, 최소 주문량·고정 바지 수수료의 미반영을 명시했다. 소량 반복 급유의 실무 실행 가능성을 평가하지 못했으며 step과 실제 일수, 급유 행동과 실제 기항을 동일시할 수 없음을 추가했다. 고정 안전선의 잔여 항해 소비량·사용 불가 잔량·연료 종류 표현 한계도 명시했다. 미확인 일수·비용·최소 주문량 수치는 도입하지 않았다.

## 검증 범위

- v7.0 대비 표 4개의 모든 셀과 삽입 그림 보존.
- 실험 결과·실선 집계 수치·참고문헌 보존; 초록에는 본문의 기존 53.97% 결과를 명시.
- Word와 Markdown 본문 일치 검사 및 PDF 3쪽 시각 검수.
- 모델·환경·보상·평가 코드는 변경하지 않음. 수정 환경 재학습과 보상 항 제거 실험은 미수행.
- 저자 순서·영문 성명·소속·이메일의 당사자 확인 및 멘토 최종 검토는 대기.
