## 검수와 남은 확인

DOCX를 PDF로 렌더링하여 전 3쪽의 제목·본문·표·참고문헌을 시각 확인했다. PDF는 텍스트 선택과 추출이 가능한 형식이다. 환경에 없는 원본 한글 글꼴은 렌더러가 대체할 수 있으므로 제출 PC에서도 최종 페이지 수를 확인한다.

저자 이메일은 확인되지 않아 `E-mail: [저자 확인 필요]`로 표시했다. 기존 저자 순서와 영문 성명·소속을 유지했으며 당사자 최종 확인을 대신하지 않는다. 멘토 승인·실제 제출은 완료로 표시하지 않는다. 이는 새 연구 버전이 아니라 v6.0의 양식 정정이다.
