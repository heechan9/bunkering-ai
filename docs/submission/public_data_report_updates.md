# 개발보고서·시연영상 공공데이터 반영안

## 사실관계 원칙

- 표지의 공공데이터 항목은 `활용`으로 표시한다.
- 울산항만공사 공공데이터는 실제 업무변수 확인과 시나리오 설계의 참고자료로 사용했다.
- 현재 Rule-based 및 Double DQN 실험 결과는 합성 데이터 기반이다.
- 공공데이터 직접 학습 입력, 실시간 API 연동, 공공데이터 기반 DQN 우위는 주장하지 않는다.

## 개발보고서 삽입 문구

### 작품의 특장점/데이터 활용

공공데이터포털에서 제공하는 울산항만공사 「벙커링정박지 신청현황」 6,028건을 분석하여
총톤수·벙커량·예정 시작일·종료일 등 실제 벙커링 신청 데이터의 변수 구조를 확인하였다.
벙커량 중앙값 200, 사분위 범위 100~500을 시나리오 설계의 참고범위로 활용하되,
극단값과 데이터 품질 한계를 고려해 현재 합성환경의 파라미터를 곧바로 대체하지 않았다.

### 작품 기능/현재 구현

울산항만공사 공공데이터의 구조·기초통계·품질 한계를 재현 가능한 스크립트와 CSV·그래프로
기록하였다. 현재 Rule-based 공식 평가와 Double DQN smoke test는 합성 시계열 기반이며,
공공데이터 직접 학습 및 실시간 API 연동은 아직 구현하지 않았다.

### 현재 구현과 향후 계획

- 현재: 공공데이터 CSV 확보, 스키마 검증, 6,028건 기술통계 및 품질검사 완료
- 현재: 총톤수·벙커량·작업 예정기간을 향후 실증 시나리오 후보 변수로 도출
- 향후: 중복·0값·일정 역전 기록에 대한 도메인 검증 후 전처리 규칙 확정
- 향후: 공공데이터 기반 환경 파라미터 캘리브레이션과 별도 학습·평가 실시
- 향후: API 제공 조건 확인 후 자동 갱신 파이프라인 검토

### 구성도 추가 요소

`울산항만공사 공공데이터`에서 `시나리오 설계·실증 검증`으로 향하는 점선 화살표를
추가한다. 공공데이터가 현재 DQN에 직접 입력되는 것으로 오해되지 않도록 BunkeringEnv의
현재 입력선과 분리한다.

## 영상 수정안

### 입력정보 장면 자막

`공공데이터 참고: 울산항만공사 벙커링정박지 신청현황 6,028건`

### 내레이션

"현재 학습 실험은 합성 시계열을 사용합니다. 별도로 울산항만공사의 벙커링정박지
신청현황 6,028건을 분석해 총톤수, 벙커량, 작업 예정기간 등 실제 업무 변수의 구조를
확인하고 향후 시나리오 설계의 참고자료로 활용했습니다."

### 현재/향후 구분 자막

- 현재: 공공데이터 구조·기초통계 분석 및 시나리오 참고
- 향후: 공공데이터 직접 입력·API 연동·재학습 및 공식 비교평가

### 첨부할 실제 자료

- 공공데이터포털 데이터 상세 페이지 캡처
- `upa_bunkering_reference_summary.png`
- `upa_summary_metrics.csv`
- 저장소의 `docs/data/upa_bunkering_anchorage.md`

### 영상 생성 금지사항

- 공공데이터가 현재 DQN 학습 입력으로 사용됐다고 표현하지 않기
- 공공데이터 기반 성능 향상 수치 생성하지 않기
- 실시간 API 연동 화면을 현재 기능처럼 생성하지 않기
- 벙커량의 단위를 원자료에 없는 통화·톤 등으로 임의 확정하지 않기
